### 작업 7 — P0-2/3: Taranis Wire 전파 + 자연 소멸 정식 구현

**진단 중 발견**: Wire는 메인 타겟에게조차 Charge를 안 부여하고 있었음 (플레이어 Attack 스킬 StatusEffect 공통 누락). TurnManager의 네트워크 연쇄 코드만 있고 실제 Charge는 안 쌓이는 상태.

**해결**:
- `BehaviorKeyword.Propagate` 신규 — PostApply Phase에서 메인 타겟 제외 다른 적 N명(전하 보유 우선)에게 Charge 부여
- `PropagateBehavior` 신규 + BehaviorRegistry 등록
- Wire의 `Chain(1)` → `Propagate(1)` 교체 (DataGenerator.PhaseCC.cs)
- `SkillExecutionPipeline.ExecuteAttack`에 Attack 스킬 StatusEffect 공통 부여 로직 추가 (Wire-Charge 자동 작동)
- `StatusEffectComponent.Charge` 특수 처리 — value 누적(캡 3) + TickTurnEnd에서 duration 소멸 스킵 (value 기반 자연 소멄만)
- `TurnManager.ProcessTurnEnd`에 매 턴 Charge value -1 코드 추가 (0이면 제거)

- BehaviorTag 요약: `HP≤50% 2배` / `빙결 적 +3` / `전파` / `자원 3+ 강화` 등 (GetBehaviorLabel 20종)

### 작업 14 — ResourceBadge 대형 원형 디자인 (StS/Hearthstone 참고)

**문제**: 기존 자원 표시가 NameRow 한 줄 텍스트(`Ember 3/5`)로 존재감 없음. 매 턴 자원 변화를 직관적으로 파악 어려움.

**참고**: Slay the Spire 에너지 구슬, Hearthstone 마나 크리스탈, Darkest Dungeon Torch 경고.

**신규 디자인**:
- 44x44 원형 배지 — 자원별 고유 색상 테두리 + 어두운 내부 배경
- 중앙 큰 숫자(18pt) + 하단 작은 이니셜(9pt) — 자원 종류 직관 식별
- 자원 변화 시 DOTween 펀치 스케일 + 플로팅 텍스트(`+1 잿빛`)
- ★ 임계값(WarningThreshold) 도달 시 빨강 깜빡임(Yoyo 루프) — 위험도 직관 전달
- 툴팁 부착 (자원 설명)

### 작업 15 — PlayerSidebarPanel 레이아웃 수정

**문제**: ResourceBadge가 패널 좌상단(Avatar 영역)에 배치되면서 캐릭터 이름과 시각적 충돌. 1차 시도(이름을 HPBar 안으로 이동)는 HP 텍스트 "70/70"과 겹침 문제 발생.

**해결**:
- 이름은 NameRow(HPBar 바로 위 행)에서 전체 너비 사용 (좌측 정렬)
- Stats(ATK/DEF)는 NameRow 우측에 작게 배치 (12pt, 우측 정렬)
- ResourceBadge 크기 56→44px 축소 — Avatar(48px) 영역 내 위계, 패널 전체 높이(64px) 독점 방지
- `CharacterResourceComponent` — OnStacksChanged 이벤트 + WarningThreshold 가상 프로퍼티 추가
