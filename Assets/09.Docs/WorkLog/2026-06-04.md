## 5. 보너스 AP 파이프라인

### 데이터 흐름
```
GameRunState.MeditateAtCampfire() → BonusAP = 1
  ↓
MapSceneSetup.StartBattle() → _runState.ConsumeBonusAP()
  ↓
BattleSceneSetup.SetBattleData(party, enemies, bonusAP)
  ↓
TurnManager(bonusFirstTurnAP: bonusAP)
  ↓
StartNewTurn() 첫 턴: AP = 1 + aliveCount + bonus
```

## Phase 4I: 런타임 버그 수정 2건 + 자동화 테스트 인프라

### 버그 수정

#### 1. BattleEndOverlay 미표시
- **증상**: 전투 승리 시 승리 오버레이가 나오지 않음
- **원인**: `BattleEndOverlay.Awake()`에서 `gameObject.SetActive(false)` 호출
  - 씬 빌더가 비활성 상태로 저장 → 런타임에 `Show()`로 활성화 → Unity가 지연된 `Awake()` 호출 → `Awake()`가 다시 비활성화 → 오버레이 즉시 사라짐
- **수정**: `Awake()`에서 `gameObject.SetActive(false)` 제거

#### 2. 보스 승리 후 층 이동 불가 + 골드 즉시 갱신 안 됨
- **증상**: 보스 전투 승리 후 다음 층으로 넘어가지 않음, 보상 골드가 MapView에 즉시 반영되지 않음
- **원인**: `RewardUI.HideAndNotify()` 코루틴에서 `FadeOut()`이 `gameObject.SetActive(false)`를 호출 → 코루틴 즉시 종료 → `_onRewardComplete?.Invoke()` 미실행 → `MapSceneSetup.OnRewardComplete()` 누락
- **수정**: `_onRewardComplete?.Invoke()`를 `FadeOut()` 이전으로 이동

### 자동화 테스트 인프라

#### Unity 함정 체크리스트 (CLAUDE.md 추가)
