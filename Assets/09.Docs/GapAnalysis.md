# 턴제 로그라이크 비교 분석 보고서

> 8개 타이틀 대상: Slay the Spire, Darkest Dungeon, Monster Train, Into the Breach, Gloomhaven, Balatro, Wildfrost, Ring of Pain

## 현재 구현 현황

| 시스템 | 구현 상태 | 상세 |
|--------|----------|------|
| 턴제 전투 | **완료** | AP/드로우/리롤, 14종 상태이상, 13종 적 특성, 6종 스킬 타입 |
| 맵 시스템 | **완료** | 3층 프로시저럴 맵, 7가지 노드 타입 |
| 보상 | **기본** | 골드/스킬/아이템 3개 중 1개 선택 |
| 상점 | **기본** | 구매만 가능 (판매/리롤/제거 불가) |
| 휴식 | **완료** | 휴식/수련/명상 3선택지 |
| 이벤트 | **기본** | 10개 이벤트, 골드/HP/스킬/아이템 결과 |
| 아이템 | **매우 얕음** | 6종, 전부 즉시 스탯업, 3개 효과 미구현 |
| 스킬 | **매우 제한적** | 16개 고정 (클래스당 4개), 업그레이드/제거 불가 |
| 사운드/VFX | **완료** | 42개 SFX, 13개 VFX, 카메라 셰이크 |
| 저장 | **코드만** | SaveManager 구현 완료, 호출 안 됨 |
| 타이틀 화면 | **없음** | MapScene 직접 진입 |
| 메타프로그레션 | **없음** | 런 간 영구 성장 없음 |

## 1순위: 메타프로그레션

### 현황
- 런 종료 후 아무것도 남지 않음
- 타이틀 화면 없음 (MapScene 직접 진입)
- OnRunEnded 이벤트에 핸들러 없음 (승리/패배 시 아무 일도 안 일어남)
- SaveManager.Save()가 호출되는 곳 없음

### 비교
| 게임 | 메타프로그레션 |
|------|----------------|
| Slay the Spire | Ascension 1~20, 캐릭터별 카드/유물 잠금해제 |
| Balatro | 스테이크 8단계, 15종 덱 해금 |
| Monster Train | Covenant 1~25, 클랜 잠금해제 |
| Darkest Dungeon | 마을 건물 업그레이드, 영웅 레벨 |

### 개선 방안
- TitleScene + TitleSceneSetup (새 게임 / 이어하기)
- MetaSaveData (런 간 통계: 총 런 수, 승리 수, 최고 층)
- RunEndOverlay (런 승리/패배 화면)
- 자동 저장 (층 이동, 휴식, 상점, 이벤트 후)

## 1순위: 스킬 성장

### 현황
- 4 클래스 × 4 스킬 = 16개 고정
- 스킬 업그레이드 불가 (SkillData가 공유 ScriptableObject)
- 스킬 제거 불가 (드로우 풀 희석 문제)
- 휴식지에 업그레이드 선택지 없음
- 상점에 제거 서비스 없음

### 비교
| 기능 | StS | MT | Balatro | **Team Log** |
|------|-----|-----|---------|-------------|
| 스킬 획득 | O | O | O | **O** |
| 스킬 업그레이드 | O | O | O | **X** |
| 스킬 제거 | O | O | O | **X** |

### 개선 방안
- SkillInstance 래퍼 (SkillData + UpgradeLevel)
- 휴식지 "강화" 선택지 추가
- 상점 "제거" 서비스 추가

## 2순위: 유물 시스템

### 현황
- 아이템 6종, 전부 "스탯+N" 즉시 적용
- 룰을 변경하는 패시브 유물 없음
- ItemType.Relic enum은 있으나 PassiveBuff와 동일 동작
- 전투 이벤트 버스 없이 패시브 트리거 불가

### 비교
| 게임 | 패시브 아이템 |
|------|--------------|
| Slay the Spire | 150+ 유물 (룰 변경: "턴 시작 시 에너지+1" 등) |
| Balatro | 150 조커 (칩/멀티/조건부) |
| Monster Train | 50+ 아티팩트 |
| **Team Log** | **6개 (전부 스탯+N)** |

### 개선 방안
- CombatEventBus (전투 중앙 이벤트 버스)
- RelicData (트리거 + 효과 SO)
- RelicHandler (EnemyTraitHandler 패턴 활용)
- ~15종 유물 정의

## 2순위: 타이틀 + QoL

### 부족한 QoL
| 기능 | StS | DD | ITB | **Team Log** |
|------|-----|-----|-----|-------------|
| 튜토리얼 | O | O | O | **X** |
| 덱/스킬 조회 | O | - | O | **X** |
| 전투 속도 조절 | O | - | O | **X** |
| 런 통계 | O | - | - | **X** |

## 3순위: 상점 / 이벤트 깊이

### 상점
- 판매 불가 (SellSkill 백엔드는 존재하나 UI 없음)
- 리롤 불가
- 스킬 제거 서비스 없음

### 이벤트
- 부정적 결과 거의 없음 (저주, 디버프 부재)
- 연쇄 이벤트 없음
- 파티 상태 참조 불가

### 미구현 ItemEffectType
- HealPerTurn, ExtraGold, DrawWeightBonus — enum만 정의, 구현 없음

## 3순위: 소모성 포션

- ItemType.Consumable enum 존재하나 사용 불가
- 전투 중 사용 메커니즘 없음
- 인벤토리 슬롯 없음
