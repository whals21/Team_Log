# Team Log - Design Pillars (디자인 기둥)

> **작성일**: 2026-06-26
> **문서 위상**: 모든 기획/밸런스/콘텐츠 설계의 **최상위 북스타(North Star)**
> **활용**: 신규 캐릭터/스킬/특성/증강/유물 설계 시 반드시 참조. 기존 설계 검토 시 체크리스트로 사용.

---

## 0. 문서의 목적

Team Log의 **"왜 만드는가, 무엇을 추구하는가"**를 한 곳에 명문화하여:

1. **일관성 유지** — 신규 콘텐츠 설계 시 방향성 흔들림 방지
2. **안티패턴 감지** — "완벽한 캐릭터"로 수렴하는 설계를 사전 차단
3. **의사결정 기준** — 기획 충돌 시 상위 원칙으로 판단
4. **협업 언어** — 팀원/협업자/AI 에이전트와 디자인 용어 공유

본 문서는 GameDesign.md(규칙), CharacterConceptReview.md(캐릭터 설계)의 **상위 철학**을 담습니다. 충돌 시 본 문서가 우선합니다.

## 1. 핵심 비전 (North Star)

> **"드로우 운을 전략으로 바꾼다. 매 턴 뽑힌 조각으로 퍼즐을 풀게 하라."**

Team Log가 다른 턴제 로그라이크와 차별되는 단 한 문장입니다.

### 핵심 가설

> **"조건부 보상은 턴 설계를 게임으로 만든다."**

무조건 강한 스킬은 AP 계산으로 끝납니다. 하지만 *"대상이 도트 디버프 상태일 때 +50%"*, *"이번 턴 힐을 받은 아군의 다음 공격에 +3"* 같은 조건부는 플레이어가 매 턴 조건을 채우기 위해 순서·타겟·타이밍을 고민하게 만듭니다. 이것이 Slay the Spire / Darkest Dungeon / Into the Breach가 공유하는 핵심 재미 요소이며, Team Log가 추구하는 바입니다.

---

## 2. 핵심 USP (Unique Selling Proposition)

Team Log를 한 문장으로 설명할 수 있는 4가지 축:

| 축 | 내용 |
|----|------|
| **전투** | 매 턴 캐릭터당 1슬롯 가중치 랜덤 드로우. 4인 파티 = 16슬롯 퍼즐. 뽑은 스킬로 고민 |
| **파티** | 단일 영웅이 아닌 4인 파티 운영. 사망자 부활 + 누적 약화로 "파티 단위 생존" |
| **컨셉** | 각 캐릭터는 강력한 정체성(Ember/Vengeance/Frost/Storm/Combo) 보유. 단, 명확한 약점 동반 |
| **확장** | 10 캐릭터 × 4 스킬 × N 증강 × M 특성 × K 유물 = 조합 폭발. 신캐 추가 대신 빌드 다양성 |

## 3. 3대 디자인 원칙

모든 스킬/캐릭터/특성/증강/유물 설계는 이 원칙을 따릅니다. 위반 시 설계 재검토.

### 원칙 1: 드로우 운을 전략으로 (Draw Luck → Strategy)

> **"어떤 스킬이 뽑힐지는 운이지만, 뽑힌 스킬로 무엇을 할지는 전략이다."**

#### 의미
- 매 턴 등장하는 4슬롯(캐릭터당 1개)이 **정답 한 개**가 아니라 **여러 정답**을 허용해야
- "운 좋게 최강 스킬 뽑음" → 승리, 가 아니라 "뽑힌 약한 스킬 조합으로도 상황을 해결하는 법"이 있어야
- 드로우 가중치(현재 25 균등)는 **캐릭터 내 스킬 간 균등**을 전제

#### 적용 규칙
- 각 캐릭터의 4스킬은 **서로 다른 조건**을 가져야 (캐릭터당 매 턴 다른 퍼즐) — *CharacterConceptReview.md 4.5 원칙 준수*
- 만능 스킬 (모든 상황에 강함) **금지**
- 비슷한 효과의 변형 스킬 2개 분리 **금지** (예: "전체 도발" + "단일 도발")
- 조건부 스킬은 **강화 조건**(항상 사용 가능, 조건 충족 시 보너스)이 기본. 사용 제약 조건(조건 미충족 시 사용 불가)은 4스킬 중 최대 1개

#### 위반 사례 (안티패턴)
- "적 1~2마리일 때 전체 도발, 3+마리일 때 상위 2마리만 도발, 분노 5+일 때 +1턴" → 만능 자동 대응. 드로우 운이 무의미
- "대상 도트 상태일 때만 사용 가능, 데미지 +50%" → 매 턴 도트 기다림. 드로우 운이 이중 작용

### 원칙 2: 약점-보조 구조 (Weakness & Compensation)

> **"캐릭터는 불완전하다. 그 불완전함이 플레이어의 선택 재료다."**

#### 의미
- 캐릭터는 **강점(strength)** + **설계된 약점(weakness)** 의 결합으로 설계
- 약점은 기획자가 **의도적으로 부여** (Ashe의 자해, Duran의 안 맞으면 출력 0 등)
- 약점 메꾸는 **보조 수단은 플레이어가 선택** (특성 3종 / 증강 / 파티 조합 / 유물 / 아이템 중 택)
- **보조는 "완화"만 허용, "완전 제거" 금지** — 잔존 약점이 있어야 다음 선택지가 의미 있음

#### 약점의 종류 (5가지 카테고리)

캐릭터 간 차별화를 위해 약점 종류를 분산:

| 약점 유형 | 설계 의미 | 적용 캐릭터 (Phase CC 기준) |
|----------|----------|--------------------------|
| **자원 의존** | Pyre/Ember/Frost/Storm/Combo 축전 전까지 취약 | Ashe, Cryomancer, Stormcaller, Rogue |
| **자연 제한** | 특정 조건(피격 등) 안 되면 출력 0 | Duran, Bard |
| **역할 특화** | 단일/광역, 공격/서포트 중 한쪽만 | Archer(단일), Stormcaller(광역), Healer(서포트) |
| **자기 위험** | 자해, 희생, HP 임계 위험 | Ashe, Healer(Martyr 특성) |
| **자원 효율** | 고AP 비용, 느린 충전 | Alchemist, Necromancer |
| **누적 약화** | 사망 페널티 (부활 시스템과 연동) | 전 캐릭터 공통 |

#### 보조 수단의 계층 (4 Layer)

| Layer | 매체 | 특징 |
|-------|------|------|
| **L1** | **캐릭터 고유 스킬 4개** | 종속형. 자원 메카닉과 강결합. 컨셉의 핵심 |
| **L2** | **공용 스킬 풀 (Colorless)** | 보조층. 자원 메카닉 무관한 순수 유틸리티만 (드로우 가중치, AP 환급, 골드 등). 비율 15% 이하 |
| **L3** | **스킬 증강 (Augment)** | BehaviorKeyword 24종. 스킬 자체의 변형으로 빌드 다양성 담당 |
| **L4** | **특성 + 유물** | 캐릭터 종속적(L4-특성) + 공통(L4-유물). 약점 보조의 주된 매체 |

#### 적용 규칙
- 각 캐릭터는 **최소 1개 이상의 명확한 약점**을 가진다
- 약점은 **보조 수단 선택지가 2개 이상** 존재해야 (단일 정답 X)
- 보조 수단은 약점을 100% 제거하면 안 됨 — 잔존 약점이나 새로운 트레이드오프 발생
- 보조 조합이 **완벽 캐릭터**를 만들면 밸런스 튠 대상

#### 위반 사례 (안티패턴)
- `Trait_AshImmunity` (Ember 자해 면역) → 약점 완전 제거, **금지**
- `Trait_PerfectAim` (Archer Mark 적용 시 항상 치명타) → 약점(도트 의존)을 무시하는 완벽 마무리, **금지**
- `Relic_AutoRevive` (사망 시 100% HP 즉시 부활, 무제한) → 사망 페널티 완전 제거, **금지**

### 원칙 3: 강점의 명확성 (Clarity of Strength)

> **"캐릭터가 무엇을 잘하는지 한 문장으로 설명될 것. 그렇지 않으면 컨셉이 아니다."**

#### 의미
- 각 캐릭터는 **"이 캐릭터는 OOO이다"** 라는 한 문장 정체성을 가진다
- 정체성은 스킬 셋 + 고유 메카닉 + 시각적 연출 + 배경 스토리로 **다층 강화**
- 약점은 정체성을 훼손하지 않는 방향에서 부여 (Ashe가 화염 딜러인데 "화염 약함"은 안 됨)

#### Phase CC 캐릭터 정체성 한 문장 요약

| 캐릭터 | 정체성 한 문장 | 강점 | 약점 |
|--------|--------------|------|------|
| **Ashe, the Pyromancer** | 타오르는 자, 자신을 재로 삼아 적을 불태운다 | 화염 단일 폭딜 + Ember 자원 축적 | 자해 (Ember×2/턴 누적) |
| **Duran, the Warrior** | 불멸의 성벽, 받은 고통을 역심으로 전환 | Vengeance 탱커 + 버스트 딜 | 비피격시 출력 0 |
| **Cryomancer** | 빙결의 통제자, 적의 행동을 영원히 얼린다 | Freeze 행동 봉쇄 + 자가 콤보 | 도트 데미지 약함 |
| **Stormcaller** | 폭풍의 연쇄자, 다수의 적을 번개로 엮는다 | 광역 연쇄 + 약점 exploit | 단일전 약함 |
| **Rogue** | 콤보 암살자, 적재된 인의 일격이 결정타 | 콤보 5 폭딜 + 도트 보너스 | 콤보 축전 전 취약 |
| **Archer** | 표식 사냥꾼, Mark로 적을 노려 처치 | Mark 마무리 + 군중 제압 | 도트 없으면 빈약 |
| **Healer** | 생명 순환 서포터, 힐과 정화를 동시에 | 힐+정화 다기능 + 영구 버프 | 자기 생존 약함 |
| **Necromancer** | 영혼 수확자, 죽음을 자원으로 삼는다 | 소환 + 처치 폭발 + 영혼 자원 | 빈사 적에게 약함 |
| **Alchemist** | 시약 반응 촉매자, 물약으로 전장 조작 | 물약 효율 + 도트+힐 하이브리드 | 고AP 비용 |
| **Bard** | 리듬 지휘자, 곡이 쌓여 피날레로 터진다 | 리듬 4 피날레 + 다중 버프 | 턴당 스킬 밀도 |

#### 적용 규칙
- 신규 캐릭터/스킬 추가 시 정체성 한 문장을 먼저 정의
- 스킬 4종은 **정체성과 일관되게** (Ashe에게 냉기 스킬 X)
- 고유 메카닉(Ember 등)은 정체성과 **직접 연결** (Ashe=Ember, 분리 불가)
- 정체성을 훼손하는 보조 수단 금지 (예: Ember 면역 특성은 Ashe 컨셉 붕괴)

## 4. 설계 체크리스트 (신규 콘텐츠 작성 시 필수)

### 4.1 신규 스킬 설계 체크리스트

- [ ] 이 스킬은 **어떤 캐릭터의 정체성**과 일치하는가? (원칙 3)
- [ ] 이 스킬의 조건은 **한 가지 상태만** 체크하는가? (원칙 1, 단일 조건)
- [ ] 4스킬 중 **서로 다른 조건**인가? (원칙 1, 매 턴 다른 퍼즐)
- [ ] 이 스킬은 **만능**(모든 상황에 강함)이 아닌가? (원칙 1)
- [ ] 이 스킬이 **사용 제약 조건**이라면 3가지 기준(게임체인저/3배위력/루프종착지) 충족하는가? (원칙 1)
- [ ] 기본 수치(조건 미충족 시)가 **그 자체로 의미** 있는가? (원칙 1)

### 4.2 신규 특성/증강 설계 체크리스트

- [ ] 이 특성/증강은 **어떤 캐릭터의 약점**을 메꾸는가? (원칙 2)
- [ ] 그 약점을 **완전 제거**하는가, **완화**하는가? (원칙 2, 완화만 허용)
- [ ] 보조 방식이 **단일 정답**인가, **여러 선택지 중 하나**인가? (원칙 2, 복수 허용)
- [ ] 약점-보조 조합이 **트레이드오프**를 가지는가? (원칙 2, 보조하면 다른 것 포기)
- [ ] 이 특성이 캐릭터의 **정체성을 훼손**하는가? (원칙 3, 훼손 금지)

### 4.3 신규 유물 설계 체크리스트

- [ ] 이 유물은 **트리거 조건**이 명확한가? (원칙 1, 언제 발동하는지 분명)
- [ ] 발동 보상이 **트레이드오프/상황의존**인가? (원칙 2)
- [ ] 보상이 특정 캐릭터에 **치우쳐 있지 않은가**? (원칙 3, 특정 캐릭터 전용 효과는 부분적일 것)

### 4.4 신규 캐릭터 설계 체크리스트

- [ ] 정체성 한 문장을 정의했는가? (원칙 3)
- [ ] 강점 1 + 약점 1 이상 명시했는가? (원칙 2)
- [ ] 약점을 메꿀 **보조 수단 2가지 이상** 존재/설계 가능한가? (원칙 2)
- [ ] 고유 메카닉이 정체성과 직결하는가? (원칙 3)
- [ ] 4스킬이 4개 다른 조건을 가지는가? (원칙 1)
- [ ] 기존 캐릭터와 **정체성이 겹치지 않는가**? (원칙 3)
- [ ] 기존 캐릭터와 **약점 종류가 다른가**? (원칙 2, 같은 종류 약점이면 차별화 약화)

## 5. 안티패턴 카탈로그 (금지 설계)

### 5.1 "완벽 캐릭터" 안티패턴

| 사례 | 문제 | 수정 방향 |
|------|------|---------|
| 스킬이 모든 상황에 강함 (자동 전환, 다중 효과) | 드로우 운이 운으로 환원 | 단일 조건 + 명확한 약점 부여 |
| 4스킬이 비슷한 조건 중복 | 매 턴 같은 퍼즐, 드로우 운 결정 | 4개 다른 조건으로 재설계 |
| 증강/특성으로 약점 100% 메꿈 | 캐릭터가 완벽해짐 → 리텐션 붕괴 | 보조는 완화만, 잔존 약점 유지 |

### 5.2 "드로우 운 이중 작용" 안티패턴

| 사례 | 문제 | 수정 방향 |
|------|------|---------|
| 사용 제약 조건 남용 (3스킬 이상이 조건부 사용 불가) | 매 턴 특정 조건 기다림 지옥 | 강화 조건(항상 사용 가능) 기본, 사용 제약은 최대 1개 |
| 비슷한 효과 변형 스킬 분리 (단일 도발 + 전체 도발) | 원하는 쪽 안 뽑히면 좌절 | 하나의 스킬로 통합, 다른 캐릭터 역할로 해결 |

### 5.3 "정체성 훼손" 안티패턴

| 사례 | 문제 | 수정 방향 |
|------|------|---------|
| 캐릭터 컨셉과 무관한 스킬 (Ashe 냉기 스킬) | 정체성 희석 | 스킬 4종 전부 정체성과 일관 |
| 자원 면역 특성 (Ember 자해 면역) | 컨셉 자체 소거 | 자원과 강결합 구조 유지, 약점은 다른 방향에서 보조 |
| 정체성 없는 만능 캐릭터 | "무엇을 잘 하는지 모르겠음" | 한 문장 정체성부터 재정의 |

## 6. 캐릭터별 약점-보조 매트릭스

현재 설계된 10캐릭터의 약점과 보조 수단을 정리. 신규 캐릭터 설계 시 **중복 회피**에 사용.

### 6.1 약점 카탈로그

| 캐릭터 | 강점 | 설계된 약점 | 약점 종류 |
|--------|------|-----------|---------|
| Ashe (Pyromancer) | 화염 단일 폭딜 + Ember 자원 | 자해 (Ember×2/턴 누적) | 자원 의존 + 자기 위험 |
| Duran (Warrior) | Vengeance 탱커 + 버스트 | 비피격시 출력 0 (자연 제한) | 자연 제한 |
| Cryomancer | Freeze 행동 봉쇄 | 도트 데미지 약함 | 역할 특화 |
| Stormcaller | 광역 연쇄 + 약점 exploit | 단일전 약함 | 역할 특화 |
| Rogue | 콤보 5 폭딜 + 도트 보너스 | 콤보 축전 전 취약 | 자원 의존 |
| Archer | Mark 마무리 + 군중 제압 | 도트 없으면 빈약 | 역할 특화 |
| Healer | 힐+정화+영구 버프 | 자기 생존 약함 | 자기 위험 |
| Necromancer | 소환 + 처치 폭발 + 영혼 | 빈사 적에게 약함 | 자원 효율 |
| Alchemist | 물약 효율 + 도트+힐 하이브리드 | 고AP 비용 | 자원 효율 |
| Bard | 리듬 4 피날레 + 다중 버프 | 턴당 스킬 밀도 부족 | 자연 제한 |

### 6.2 보조 매체 분배 (균형 점검용)

각 캐릭터의 약점을 메꾸는 보조 수단이 **4 Layer**에 분산되어 있는지 점검. 한 Layer에 치우치면 해당 매체 드롭 운이 과도하게 작용.

> 상세는 캐릭터별 개별 문서 (`Assets/09.Docs/Characters/[Name]_the_[Class].md`) 참조.

## 7. 밸런스 검증 프레임

### 7.1 핵심 KPI

| 지표 | 목표 | 측정 도구 |
|------|------|---------|
| **조건 충족률** | 60%+ | 단위 테스트 / 시뮬레이터 로그 |
| **캐릭터 픽 다양성** | 특정 캐릭터 50%+ 집중 금지 | Quick Combat / Full Run 결과 |
| **어센션 클리어율 곡선** | 어센션 0/5/10/15 = 70/50/30/15% | Full Run 시뮬레이터 100회 |
| **보조 수단 사용 다양성** | 특정 특성/증강 점유율 40% 미만 | Quick Combat 스킬 사용 통계 |
| **평균 사망/런** | 1~2회 | Full Run 시뮬레이터 |

### 7.2 위험 시나리오와 대응

| 시나리오 | 조기 경고 신호 | 대응 |
|---------|--------------|------|
| 조건부 스킬이 안 쓰임 | 사용률 30% 미만 | 조건 완화 또는 기본 수치 강화 |
| 특정 조합 사기 | 승률 90%+ | 보조 매체 밸런스 튠 (원칙 2 위반 점검) |
| AP 무한 루프 | 턴당 스킬 7+ 사용 | AP 환급 매체 제한 (원칙 1 위반 점검) |
| 완벽 캐릭터 등장 | 특정 빌드 승률 95%+ | 약점 완전 제거 매체 식별 → 너프 (원칙 2 위반) |
| 정체성 붕괴 | 캐릭터 픽 이유가 애매함 | 스킬 셋 점검 (원칙 3 위반) |

## 부록: 원칙 간 충돌 시 우선순위

드자인 결정 중 원칙이 충돌할 경우, 다음 순서로 판단:

1. **원칙 1 (드로우 운 전략)** — 최우선. 이것이 흔들리면 게임 정체성 소멸
2. **원칙 3 (강점 명확성)** — 캐릭터 정체성 붕괴 방지
3. **원칙 2 (약점-보조)** — 밸런스 세부 조정 단계에서 적용

단, **안티패턴(금지 사례)** 은 모든 원칙 위에 우선합니다. 안티패턴 해당 설계는 어떤 원칙 이익을 위해서라도 허용하지 않습니다.
