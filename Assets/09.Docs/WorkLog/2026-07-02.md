## 작업 3 — Pipeline 모든 타입 확장 (핵심 아키텍처)

### 문제 인식
- Pipeline.ExecuteAttack이 Attack 타입만 처리 → Heal/Shield/Buff에 자원 비례 위력/BehaviorTag 미적용
- Phoenix Renewal(Heal)의 Ember×3 보너스가 무시되는 구조적 버그

### 해결
- **Pipeline.ExecuteSkill** 신규 — 모든 타입 통합 진입점
  - Attack → ExecuteAttack (기존 유지)
  - Heal → ExecuteHealViaPipeline (자원 비례 + Behavior + HealMul)
  - Shield → ExecuteShieldViaPipeline (자원 비례 + Behavior + ShieldMul)
  - Buff/Debuff → ApplyEffectViaPipeline (장착 특성 DurationAdd/EffectMul 포함)
  - Purify → 인라인
- SkillExecutor.ExecuteSkillInternal 단순화 — Pipeline.ExecuteSkill 1줄 호출
