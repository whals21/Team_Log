# 2026-06-30 작업 일지

## 작업 요약

어센션 `EnemyAtkPercent` modifier 제거 + 보스 12종 atk/def=0 일관화 + F3/F4 보스 너프를 통해 **"스킬 위력 = 실데미지" 단순화 원칙**을 시스템 전체에 통일 적용.

## 작업 배경

### 설계 의도 재확인
- `CharacterTable.csv`에서 플레이어 8종 + 일반/엘리트 적 18종은 이미 atk=0/def=0.
- 이는 "스킬 위력 = 실데미지" 단순화 (StS/Balatro 철학) — `DamageCalculator` 공식 `Max(1, ATK + Power - DEF)`에서 ATK=0/DEF=0이면 `damage = Power`가 되어 플레이어가 스킬 카드 숫자만 보고 직관적 계산 가능.
- **Phase ASC-B에서 보스 12종에만 atk/def 5~14/3~7을 넣어 일관성 훼손** → 이번 작업으로 보스도 0으로 되돌림.
- `Balance_Diagnostic_Report_2026-06-19.md`의 P0-1 "ATK/DEF 결함" 진단은 오판이었음을 철회 (보고서 상단에 업데이트 노트 추가).

### 어센션 EnemyAtkPercent 무의미
- `BattleSceneSetup.ApplyAscensionModifiers`에 이미 "baseATK=0이면 no-op" 주석이 있었음.
- 시스템 전체 ATK=0 구조에서 존재 의미 없음 → enum/매니저/DataGenerator/테스트에서 제거.
