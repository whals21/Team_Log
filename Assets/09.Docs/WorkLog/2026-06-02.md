## 적 특성(Enemy Trait) 시스템 구현 — Phase 4G

### 개요
적마다 고유 패시브 특성을 부여하여 전투의 전략적 깊이 추가. 각 적은 하나의 특성을 가지며, 피해 계산/턴 시작/사망 직전 등의 훅에서 자동 발동.

### 적별 특성 배정
| 적 | 특성 | 효과 |
|----|------|------|
| 슬라임 | ShieldPrep (분열 준비) | 턴 시작 시 쉴드 5 획득 |
| 고블린 | Agile (민첩) | 25% 확률로 공격 회피 |
| 정예 기사 | Sturdy (견고) | 매 턴 첫 공격 데미지 50% 감소 |
| 마법사 고블린 | ArcaneFury (마력 폭주) | HP 50% 이하가 되는 즉시 ATK +5 |
| 암흑 슬라임 | Corrosive (부식) | 피해를 입힌 대상에게 방어감소 디버프 |
| 고블린 왕 | Enrage (광폭화) | HP 50% 이하가 되는 즉시 ATK +6 |

| 마왕 | Immortal (불사) | 치명적 피해 시 HP 1로 생존 (1회) |

### 핵심 설계 결정

**특성 훅 구조 (TurnManager.DealDamage)**
```
damage = ATK + power → defense 계산
→ target.TraitHandler.ModifyIncomingDamage()   // Agile/Sturdy/ScaleArmor
→ TakeDamage(finalDamage)                      // Immortal은 OnPreDeath로 사망 방지
→ attacker.TraitHandler.OnDamageDealtTo()      // Corrosive 방어감소
→ target.TraitHandler.OnDamageReceived()       // Enrage/ArcaneFury 즉시 체크
```

**턴 시작 훅 (TurnManager.StartNewTurn)**
```
쉴드 리셋 → enemy.TraitHandler.OnTurnStart() → AP 리셋 → 드로우
// ShieldPrep: 쉴드 5 획득, Sturdy: 첫 공격 감소 플래그 리셋
```

**특성 UI — ButtonArea 활용**
- 기존 TODO 스텁 버튼(가디언/아크카) 대신 특성 라벨을 ButtonArea에 표시
- 뱃지(StatusEffectBadge)는 버프/디버프 전용으로 유지하여 디자인 일관성 확보
- 특성 라벨 클릭 시 토글: 첫 클릭 → Info 영역에 설명 표시, 다시 클릭 → 의도 텍스트로 복원
