## 🩺 근본 원인 진단

### 원인 #1: CharacterTable.csv 데이터 결함 🔴

**확인된 사실** (직접 검증):

| 소스 | 값 |
|------|-----|
| `CharacterData.cs` 기본값 | `_baseATK = 10`, `_baseDEF = 5` |
| `CharacterTable.csv` 모든 행 | `atk=0, def=0` |
| `Char_Warrior.asset` 실제 값 | `_baseATK: 0`, `_baseDEF: 0` |

**영향**:
- 데미지 공식 `max(1, ATK + Power - DEF)` → `max(1, 0 + Power - 0) = Power`
- 캐릭터 직업별 ATK/DEF 차별화 **전무**
- 적도 동일 → 일반/엘리트/보스 간 방어력 차이 없음
- 고DEF 적이 탱커 역할을 못함 (모두 DEF=0)
- SkillCatalog.md의 "ATK 8 + Power 5 = 13" 같은 설명이 **거짓** (실제는 5)

**DataCatalog와 불일치**: 문서상 "전사 HP 100, ATK 8, DEF 5" → 실제는 "HP 120, ATK 0, DEF 0"

### 원인 #2: 시뮬레이터 Phase 7-8-E 미반영 🔴

| 시스템 | Phase | 시뮬레이터 반영 | 승률 영향 추정 |
|--------|-------|----------------|---------------|
| 캐릭터 특성 24종 (CharacterTraitData) | 8C | ❌ | **-15~20%p** (가장 치명) |
| 시작 유물 지급 (StartingRelicSlot) | 8E | ❌ | **-10~15%p** |
| 메타 강화 (ExtraReroll/PartyHealBoost) | 8E | ❌ | -5~8%p |
| 엘리트 보상 (EliteBonusType 3택1) | 7B | ❌ | -3~5%p |
| 스테이지 클리어 보상 (StageClearBonusType) | 7C | ❌ | -2~4%p |
| 테마별 이벤트 24개 + 영구 강화 | E3 | ❌ | -2~4%p |
| 연쇄 이벤트 / 조건부 / 확률 Outcome | E1 | ❌ | -1~2%p |
| **누적 승률 과소평가** | | | **-38~58%p** |

**캐릭터 특성 영향 상세**:
- `ExtraAP`: 매 턴 AP+1~2 (파티 전원)
- `ShieldPerTurn`: 매 턴 쉴드 5~8 (1회 공격 무효화)
- `DamageReduction`: 받는 데미지 -10~20%
- `PowerAdd/PowerMul`: 스킬 위력 +N, ×N

시뮬레이터의 파티는 `Character.PlayerTraitHandler`가 생성되지만 `trait=null`로 모든 훅이 no-op. 즉 **실제 플레이어는 시뮬레이터보다 훨씬 강함**.

### 원인 #3: F1 연속 전투 HP 누적 🔴

**구조적 문제**:
- F1 전투 4회 (Layer 1~4) + 보스 1회 = 총 5회
- 단일 전투 승률 100%, 평균 잔여 HP 67%
- **하지만** 힐러 힐량(12) ≪ 적 평균 DPS(25)
- HP 리커버리 불가 → 3~4번째 전투에서 고갈

**휴식(Rest) 노드 부족**:
- F1: Shop 1 + Event 1 + Rest 0~1 = 회복 0~1회
- 평균 HP 30%에서 보스 도달 → 사망

### 원인 #4: 층별 난이도 계단식 붕괴 🟡

**스케일링 곡선**:
- F1: 1.0x (승률 100%)
- F2: 1.3x (승률 보스 20%) ← **여기서 붕괴**
- F3: 1.6x (승률 보스 1%)
- F4: 2.0x (승률 보스 1%)

F1→F2 전이가 너무 가파름. F1 89% 잔여 HP에서 F2 보스 13% 잔여 HP로 76%p 하락은 단일 스케일링(1.3x)으로 설명 안 됨. **보스 자체 위력 + 층 스케일링**이 합쳐진 복합 문제.
