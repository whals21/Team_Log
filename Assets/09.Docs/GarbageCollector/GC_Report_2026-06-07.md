## Recommendations

### Priority: High (Architecture / Correctness)

1. **Extract shared UI panel logic into a base class or utility** (DP-01 through DP-06)
   - Create `PanelUIBase` MonoBehaviour with shared `SetDead()`, `UpdateStatusEffects()`, `FlashHit()`, `UpdateStats()`, `FindComponent<T>()`, and `ClearContainerChildren()` methods.
   - Estimated reduction: ~120 lines of duplicate code.

2. **Fix orphan CombatEventBus events** (OE-01, OE-02, OE-03)
   - `OnBattleEnd`: Subscribe `RelicHandler` to trigger "on battle end" relic effects, or remove if unused.
   - `OnSkillUsed`: Add subscriber or remove the event.
   - `OnGoldEarned`: This is a correctness bug -- `BonusGold` relics fire the event but gold is never added. Either `MapSceneSetup`/`GameRunState` should subscribe to add gold, or `RelicHandler` should directly call `GameRunState.AddGold()`.

3. **Complete stub logic** (SL-01, SL-02)
   - Implement `CounterDamage` relic effect (either via a new event or direct callback).
   - Implement `ExtraAP` relic effect or remove the effect type from `DataGenerator`.

### Priority: Medium (Code Quality)

4. **Consolidate color management** (HC-01 through HC-08)
   - Move all hardcoded colors from `BattleDisplayUtil`, `ActionSlotUI`, `CharacterPopupUI`, `EnemyDetailPanel`, `PlayerSidebarPanel`, and `RewardManager` into `UIPalette`.
   - Remove `ShieldBrown` duplicate from UIPalette (use `ShieldColor` only).
   - Remove dead `[SerializeField]` color fields from `ActionSlotUI`.

5. **Extract duplicate `ApplyEffect()` logic** (DP-08)
   - Move the shared "apply status effect with Shell check" logic to a single static method in `TurnManager` or a new `SkillExecutor` utility. Both `TurnManager.ApplyEffect()` and `EnemyAIController.ApplyEffect()` should call this shared method.

6. **Fix GC allocation in `SkillInventoryComponent.Skills`** (EC-01)
   - Cache the `List<SkillData>` and invalidate on mutation, or return `IEnumerable<SkillData>` with a lazy projection.

7. **Unsubscribe from static events in `BattleSceneSetup.OnDestroy()`** (EC-02)
   - Add `-=` for `TurnManager.OnSkillApplied`, `TurnManager.OnAttackMissed`, and all dynamic `Health` event subscriptions.

8. **Remove dead code** (DC-01 through DC-05)
   - `SkillInventoryComponent.DrawSkill()`: Remove if confirmed no callers.
   - `ItemEffectApplier.ApplyHealPerTurn()` and `CalculateBonusGold()`: Either implement the features or remove.
   - `StatusEffectBadge.OnBadgeClicked`: Remove or implement badge click behavior.
   - `ActionSlotUI` SerializeField colors: Remove since `GetSkillColor()` uses `UIPalette`.

### Priority: Low (Polish)

9. **Gate Debug.Log calls behind `#if UNITY_EDITOR`** (DL-01, DL-02)
   - VFXManager and SaveManager runtime logs should not appear in production builds.

10. **Consider partial class split for large files** (FS-01, FS-02)
    - `MapSceneSetup.cs` (481 lines) and `BattleSceneSetup.cs` (451 lines) are approaching the 400-line threshold per CLAUDE.md.

11. **Extract `BattleSceneSetup` event subscription into a helper** (DP-09)
    - The player/enemy event subscription loops are near-identical. A single `SubscribeCharacterEvents(Character)` method would reduce duplication and improve maintainability.
