### ✅ 4Q: 저장 시스템 (JsonUtility 기반)

**SaveManager.cs** (신규):
- `RunSaveData` / `CharacterSaveData` DTO (`[Serializable]`)
- `Save()` — 런 상태, 파티 HP/ATK/DEF, 스킬/아이템 경로를 JSON으로 저장
- `Load()` — DTO에서 파티 재구성, HP/스탯/스킬 복원, GameRunState 생성
- `DeleteSave()` — 저장 파일 삭제
- `Application.persistentDataPath/run_save.json` 사용

**ES3 → JsonUtility 전환 이유**:
- ES3 스크립트에 asmdef가 없어 글로벌 Assembly-CSharp에 컴파일됨
- TeamLog.Runtime (asmdef)에서 ES3 타입 접근 불가
- JsonUtility는 UnityEngine 내장 — 의존성 문제 없음
- `ForceKill()` 미존재 → `TakeDamage(MaxHP)`로 사망 처리

**GameRunState 확장**:
- `RestoreBonusAP(int bonus)` — 저장 복원용 BonusAP 설정 메서드
