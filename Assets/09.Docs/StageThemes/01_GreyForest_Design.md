# 스테이지 테마 기획안 — 1스테이지 후보 1: 잿빛 숲 (GreyForest)

> **문서 목적**: 현재 1스테이지 3테마가 동일 적 풀을 공유하는 문제를 해결하기 위한 첫 번째 테마 깊이기획. "재생 + 독" 키워드의 정체성을 모든 적/보스/이벤트에 관통시켜, 잿빛 숲이 **다른 테마와 확실히 다른 경험**을 제공하도록 설계.
>
> **참고 명작**: Slay the Spire Act 1 (적 = 교관), Darkest Dungeon Weald (상태이상 취약성 매핑), Hades Asphodel (환경 위험)
>
> **작성일**: 2026-07-20 / **작성자**: 전문 게임기획자 관점

---

## 1. 테마 정체성 (Theme Identity)

### 1.1 핵심 컨셉 — "죽지 않는 숲, 썩어가는 생명"

잿빛 숲은 한때 평범한 참나무 숲이었으나, 지하에서 솟아오른 **역병의 기운**이 생태계를 변이시켰다. 모든 생명이 **비정상적으로 재생**하고, 동시에 **서서히 부패**한다. 플레이어는 "재생을 봉인하지 않으면 적을 영원히 못 죽인다"는 압박과, "독을 맞으면 쉴드로 막을 수 없다"는 딜레마에 동시에 직면한다.

> **핵심 정체성 한 줄**: "이 숲에서는 죽음보다 부활이 빠르다."

### 1.2 시각적 톤 (Art Direction)

| 요소 | 설계 |
|------|------|
| **기본 색조** | 잿빛 녹색 (#4A5D3A) + 부패 보라 (#6B4C7A) + 곰팡이 황색 (#C4B660) |
| **배경** | 안개 낀 참나무 숲, 땅에서 솟아오른 포자 구름, 부패한 낙엽 |
| **적 실루엣** | 변이된 식물/곰팡이/벌레 — 비정상적 비대, 겹겹의 덩어리 |
| **오디오** | 끈적한 습기, 멀리서 울리는 썩은 고목 둔탁한 삐걱거림, 포자 확산 소리 |

### 1.3 핵심 키워드 2종의 상호작용

```
재생 (Regeneration)         독 (Poison)
   ↓                           ↓
적이 안 죽음                플레이어 HP가 서서히 감소
   ↓                           ↓
전투가 길어짐                쉴드 무력화 (DoT)
   ↓                           ↓
독이 더 쌓임                재생으로 돌파 불가
   ↓                           ↓
     ╰──────── 악순환 ──────────╯
```

**기획 의도**: 두 키워드가 개별이 아니라 **시너지 악순환**을 이룬다. 플레이어는 이 순환을 끊는 법을 배워야 한다.

## 2. 밸런스 설계 기준

### 2.1 1스테이지 평균 스탯 (Phase BALANCE 4차 세션 기준)

| 항목 | 수치 |
|------|------|
| 플레이어 평균 HP | 18 |
| 플레이어 평균 스킬 위력 | 3 |
| 일반 적 평균 HP | 5~8 |
| 엘리트 평균 HP | 13~19 |
| 보스 HP | 33~45 |

### 2.2 잿빛 숲 밸런스 가이드라인

- 일반 적 HP **약간 높음** (재생 trait 보정) — 6~9 범위
- 적 공격 위력은 **낮춤** (독이 주 딜러) — 1~2 범위
- **재생 수치는 위력의 50~80%** — 재생 때문에 안 죽지만 무한정도 아님
- **독 수치는 누적 시 위협적** — 1스택 1/턴, 2턴 지속 = 총 2 데미지 (평균 HP의 11%)

## 5. 보스 상세 기획: Verdant Terror (눈부신 공포) 리디자인

> **컨셉**: 잿빛 숲의 중심에 서 있는, 역병으로 변이된 거대한 생명체. **3페이즈 구조**로 단조로움 제거. "재생의 극단 = 분열"이라는 시각적 메타포 + "역병의 확산 = 소환"이라는 전략적 위협. StS Slime Boss 오마주 + Hades식 페이즈 전환.
>
> ★ **사용자 피드백 반영 (2026-07-20)**: 보스전에 일반 몹 소환 페이즈 추가. 단일 보스만 때리는 단조로움 해결. 멀티 타겟 관리 역량 시험.

### 5.1 기본 정보

| 항목 | 수치 |
|------|------|
| HP | 40 (Phase BALANCE 기준 F1 보스 33~45 범위) |
| ATK / DEF | 0 / 0 (스킬 위력 = 실데미지 철학 유지) |
| Class | Warrior |
| Trait | **Regenerate** (+3/턴) + **PhaseSplit** (HP 50% 도달 시 2체로 분열) + **SummonAt75** (HP 75% 도달 시 일반 몹 2체 소환) |

### 5.2 페이즈 구조 개요 (3페이즈)

```
전투 시작
   ↓
[P1: 단일 보스] (HP 100~75%)
   ↓ HP 75% 도달 시
[P1.5: 소환 이벤트] 일반 몹 2체 (Ashwood Wisp + Sporecaller) 스폰
   ↓
[P2: 보스 + 일반 몹 2체] (HP 75~50%)
   ↓ HP 50% 도달 시

   ↓
[P3: 분신 2체 + 잔존 일반 몹] (HP 50~0%)
```

### 5.3 페이즈 1 (HP 100%~75%) — 단일 보스, 폭딜 유도

**스킬 4종**:

| # | 이름 | 타입 | 타겟 | 위력 | 상태이상 | 가중치 | 설명 |
|---|------|------|------|------|---------|--------|------|
| 1 | 넝쿨 채찍 | Attack | SingleEnemy | 5 | — | 30 | 메인 타격 |
| 2 | 독성 포자 | Attack | AllEnemies | 3 | Poison (3턴, 값2) | 25 | **광역 독** — 잿빛 숲 키워드 |
| 3 | 재생 성장 | Buff | Self | 0 | Regeneration (3턴, 값5) | 25 | 매 턴 +5 회복 (위협적) |
| 4 | 속박 뿌리 | Attack | SingleEnemy | 4 | Stun (1턴) | 20 | 딜 템포 끊기 |

> **P1 의도**: 보스 단일이라 집중 딜 가능하지만, 재생(+3 trait + 재생 성장 스킬) 때문에 딜 러시 강제. 75%까지 빠르게 컷해야 소환 전에 페이즈 1 끝.

### 5.4 페이즈 1.5 (HP 75% 도달 시) — ★ 소환 이벤트

```
[Verdant Terror HP 75% 도달]
        ↓
[SummonAt75 트리거]
        ↓
[넝쿨 연출] 보스가 뿌리를 뻗어 땅에서 일반 몹을 끌어올림
        ↓
스폰: Ashwood Wisp (HP 7, 재생) + Sporecaller (HP 5, 아군 재생 버프)
```

> **소환 대상 선택 이유**:
> - **Ashwood Wisp**: 재생 trait으로 잘 안 죽음 → 플레이어 딜 낭비 유도
> - **Sporecaller**: 아군(보스+다른 몹)에게 재생 버프 → 전체 적 재생량 폭증
>
> **선택 없이 고정 스폰**인 이유: 랜덤이 아니라 "왜 이 조합인지" 전략적 의도가 보이도록. Sporecaller 방치 = 보스 +5/턴, Wisp +2/턴, Sporecaller 자신 +1/턴 = 총 +8/턴 재생. → **Sporecaller 우선 컷 강제**.

### 5.5 페이즈 2 (HP 75%~50%) — 보스 + 일반 몹 2체

보스는 동일 스킬셋 유지. 일반 몹 2체가 플레이어를 동시에 압박.

> **이 페이즈의 핵심 딜레마**:
> - 보스 딜? → 일반 몹이 플레이어를 갈기고, Sporecaller 재생 버프 누적
> - 일반 몹 딜? → 보스 50% 분열까지 시간 지연, 재생 때문에 보스 HP 다시 오를 수 있음
> - 광역 공격? → 가장 이상적이나, 광역 카드가 한정적
>
> **★ 핵심 교훈**: "멀티 타겟 관리 + 우선순위 결정". StS Hexaghost(멀티 위협) + Slime Boss(임계값)가 합쳐진 페이즈.

### 5.6 페이즈 2.5 (HP 50% 도달 시) — 분열 이벤트

```
[Verdant Terror HP 50% 도달]
        ↓
[PhaseSplit 트리거]
        ↓
기존 보스 제거 + 다음 2체 생성:
   - Verdant Terror - Left Half (HP 18, Poison 강화)
   - Verdant Terror - Right Half (HP 18, Regen 강화)

일반 몹 2체 처리 방식 (옵션):
   옵션 A: 그대로 유지 (최대 4체 동시 전투 — 매우 혼잡)
   옵션 B: 흡수되어 제거 (분신이 일반 몹을 흡수해 강해짐 — 깔끔)
   ★ 추천: 옵션 B (혼잡 방지 + 시각적 연출 "흡수" 가능)
```

**분신들의 차이**:
- **Left Half**: 모든 공격에 Poison 1 추가 부여 (독 특화)
- **Right Half**: 매 턴 Regeneration +3 (재생 특화)

> **시스템 구현 (★ 사용자 선택 b안)**: 별도 클래스 **`BossPhaseManager.cs`** 신규 생성 (`Assets/02.Scripts/Combat/BossPhaseManager.cs`). HP 임계값(75% 소환, 50% 분열) 감지, 페이즈 전환, 스폰 이벤트 처리 담당. 다른 테마 보스들도 동일 시스템 확장하여 사용 가능 (확장성 확보).

## 12. 핵심 기획 원칙 요약 (다른 테마 기획 시에도 적용)

1. **테마 정체성 = 키워드 2종의 시너지** — 단순 "X 적 등장"이 아니라, 키워드가 악순환/선순환을 이루는 구조
2. **적 1종 = 교훈 1개** — StS Gremlin Nob 철학. 복잡한 다중 기믹은 보스용
3. **역할 분담 매트릭스** — 4종 일반 적에 Tank/DPS/Support/Debuffer 각 1종씩 필수
4. **보스는 키워드의 시각적 결정체** — 외형만으로 기믹이 추측되어야
5. **HP 임계값 페이즈 전환** — 보스에 단조로움 제거 (Verdant Terror 50% 분열)
6. **상태이상 취약성 매핑** — (옵션) 테마마다 어떤 디버프가 통하는지 다르면 정체성 강화
7. **환경 위험** — (옵션) 적과 별개로 배경 자체가 테마 강조
