### 3. 부활 시스템 정책 확정 (사용자 결정)

**정책**:
| 캐릭터 상태 | 전투 종료 시 처리 |
|-----------|-----------------|
| 살아남은 자 | HP 100% 회복 |
| 사망한 자 | 50% 부활 + MaxHP 영구 -10% 누적 (곱셈) |
| 연쇄 사망 | 매번 50% 리셋, MaxHP -10% 추가 |
| 보스전 | 일반전 동일 |
| 파티 전멸 | 런 종료 |

**MaxHP 누적 예상 (Warrior 120 기준)**:
- 사망 1회: 108 / 2회: 97 / 3회: 87 / 5회: 71

**어센션 × 사망 상호작용**: 어센션 15(-10%) + 사망 3회 = 72 HP. 시뮬레이터 검증 후 사망 -10%를 -7% 또는 -5%로 완화 검토.

**이유**: 부활 시스템이 있어야 "아군 사망" 트리거 디자인이 정당화됨. Darkest Dungeon의 Death's Door + StS의 회복 중간 노선.

**4가지 규칙**:

2. 스킬 4개는 서로 다른 조건 (매 턴 다른 퍼즐)
3. 만능 스킬 금지 — 상황 자동 대응 X
4. 셋업 스킬과 소비 스킬 분리

검증 체크리스트 5종 + 반례(만능 도발) vs 올바른 설계 비교.

### 5. Warrior Bodyblock 재설계 (사용자 제안)

**문제**: 기존 Bodyblock 조건 "자신 도발 상태일 때" → 같은 턴 Taunt 선행 필요 + 매 턴 둘 다 뽑힐 보장 없음 + 단일 공격인데 광역 도발과 안 어울림

**해결**: Bodyblock이 직접 단일 도발 부여
- Taunt: 자신에게 **광역 도발** 1턴 (다수 적용)
- Bodyblock: 단일 공격 + 대상에게 **ForcedTarget 2턴** (보스 단일 묶기)

**시스템 명세**: StatusEffectType.ForcedTarget 신규 항목. EnemyAIController.SelectRandomAlivePlayer 확장 — ForcedTarget 디버프가 적에게 있으면 지정된 타겟 강제 공격.

### 6. Mage → 3원소 마법사 분할 (8→10 캐릭터)

**사용자 결정**: Mage 4원소 혼합은 과도한 기믹. 원소 전문 마법사로 분할.

**3종 신규 마법사**:
| 마법사 | 원소 | 고유 메카닉 | 역할 |
|--------|------|------------|------|
| **Pyromancer** | 화염 | Pyre (축적 → AP -1+위력+50%) | 도트 딜러 |
| **Cryomancer** | 냉기 | Frost (축적 → Freeze 1→2턴) | 통제형 |
| **Stormcaller** | 번개 | Storm (축적 → 추가 타겟+1) | 다수 광역 |

**해금 정책**:
- Pyromancer: 기본 (Mage 슬롯 계승)
- Cryomancer: F2 보스 클리어 해금
- Stormcaller: F3 보스 클리어 해금

**각 마법사 4스킬**: 원소 통일, 4개 다른 조건. Pyromancer Spark(도트 조건)/Cauterize(도트 정화)/Inferno(적 수)/Meteor(Pyre 자원).

**특성 확장**: 8캐릭 × 3 = 24 → 10캐릭 × 3 = 30종. 메타 해금 특성 8 → 10종.
