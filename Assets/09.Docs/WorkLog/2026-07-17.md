## Phase CC-2E-4: 스킬 실행 통합

### 수정
- **`PlayerActionController.cs`** (+250줄, 재작성) — 핵심 통합 지점
  - `_pendingDiscoverSkill` 필드 — 발견 스킬 진행 중 상태 추적
  - `OnSlotSelected` — `skill.IsDiscover && skill.DiscoverPool != null` 분기 추가
  - `HandleDiscoverSkill(slot)` 신규:
    - AP 부족 시 모달 표시 안 함 (기존 UX 일관성)
    - "강화 물약" 특성(ShouldApplyAll) 시 `ApplyDiscoverAll` — 모달 없이 풀 전부 발동
    - 아니면 DiscoverSystem.RollOptions + modal.Show
    - 모달 미연결 시 첫 옵션 자동 선택 (안전장치)
  - `ApplyDiscoverAll(slot)` — 풀 전부 순회하며 ResolveDefaultTarget으로 기본 타겟 결정
  - `OnDiscoverSkillSelected(skill)` — 모달 콜백, TargetType 분기 (Single은 타겟 대기, Self/All은 즉시)
  - `CastDiscoverImmediately(slot, skill, target)` — 선택 스킬을 instance=null로 ExecuteSkillImmediately 호출 (발견 본체 증강이 선택 스킬에 영향 주면 안 됨) + 본체 Cost 별도 청구
  - `FinalizeDiscoverSlot(slot)` — 슬롯 마무리 + 자동 턴 종료 검사
  - `ResolveDefaultTarget(skill, caster)` — ApplyAll 용 기본 타겟 (Self=본인, SingleEnemy=첫 적)
  - `EnterTargetSelectionMode(slot)` — 비발견 스킬 기존 로직 분리
  - `OnEnemyPanelClicked`/`OnPlayerPanelClicked` — `_pendingDiscoverSkill != null` 분기 추가
- **`BattleDisplayUtil.cs`** (+20줄):
  - BuildSkillDescription에 발견 스킬 설명 추가 (풀 카테고리 + 선택지 수)
  - `GetDiscoverCategoryLabel(category)` 헬퍼

### 핵심 설계 결정
- **AP 소모는 발견 본체 Cost** — ExecuteSkillImmediately에 instance=null 전달 (선택 스킬의 Cost는 0, 본체 Cost를 별도 SpendAP로 청구)
- **코루틴 대신 Action<SkillData> 콜백** — PlayerActionController는 순수 C#이라 코루틴 불가
- **Time.timeScale 금지** — 대신 CanvasGroup.blocksRaycast + overlay Button으로 입력 차단
