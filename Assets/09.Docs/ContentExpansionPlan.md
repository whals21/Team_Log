# Team Log — 콘텐츠 확장 기획서 (전문 기획자 관점)

> **분석 일자**: 2026-06-19
> **분석 관점**: 10년차 전문 게임 기획자 (턴제 로그라이크 장르 전문)
> **벤치마킹 대상**: Slay the Spire, Inscryption, Balatro, Monster Train, Darkest Dungeon 1/2, Hades, Into the Breach, Persona 5, Baldur's Gate 3, Divinity: Original Sin 2, Griftlands, Steamworld Quest
> **목적**: 현재 프로젝트(Phase 1-8 + E 완료)의 장기 로드맵 수립, 명작과의 격차 식별, 차별화 강화 방향 제시

## 0. 핵심 결론 (Executive Summary)

**Team Log의 현재 상태는 "기술적 기반은 훌륭하나 정체성이 흐릿한 상태"**입니다.

- ✅ **시스템 깊이**: 시너지 루프, 메타프로세션, 자동 밸런스 시뮬레이터 등 **기술적 완성도는 상위 10%**.
- ⚠️ **정체성 부재**: "랜덤 드로우 + 파티 조작"이라는 컨셉은 있으나, **이것만의 고유한 경험**이 부각되지 않음.
- 🔴 **장기 리텐션 부재**: 클리어 이후 돌아올 이유가 거의 없음 (어센션, 도전과제, 데일리 룬 등 부재).
- 🔴 **서사적 몰입 부재**: 8 캐릭터가 있으나 정체성/스토리/관계가 없음. 스테이지 테마도 "배경"에 그침.

**권장 전략**: 명작을 카피하지 말고, **Team Log만의 차별화 축(파티 시너지 + 드로우 운영)을 강화**하면서 명작의 **리텐션/학습 곡선 디자인**만 차용할 것.

## 1. 현재 프로젝트 강약진단 (SWOT)

### Strengths (강점)

| 항목 | 내용 | 명작 대비 우위 |
|------|------|----------------|
| **파티 기반 드로우** | 4 캐릭터가 각자 스킬 드로우 → 조합 전략 | StS/Monster Train은 단일 영웅. **파티 기반은 드물고 가치 있음** |
| **AP 공유 시스템** | 파티 전체가 자원 공유 → "누구의 스킬에 투자할지" 딜레마 | Darkest Dungeon과 유사하나 드로우 레이어 추가로 독창적 |
| **시너지 루프 설계** | 3 패턴(이벤트 폭포/자원 순환/조건부 배율) + 트리거 체인 | RelicSynergies.md 기준 StS급 복잡도 |
| **메타프로세션** | 8단계 Phase, 특성 Loadout, 메타 강화 30종 | Hades급 진행도 |
| **자동 밸런스 시뮬레이터** | 1000팩 Quick Combat + 100회 Full Run + Relic Synergy | **명작도 갖추지 못한 인프라**. StS 초기 2년간은 스프레드시트였음 |

### Weaknesses (약점)

| 항목 | 내용 | 명작 대비 격차 |
|------|------|----------------|
| **캐릭터 정체성** | 8캐릭터가 스탯/스킬만 다름 (대사/스토리/관계 없음) | Hades의 멜리노에-가족관계, BG3의 동료 퀘스트 대비 **심각 부족** |
| **보스 다양성** | 보스 3종 (GoblinKing/Dragon/DemonLord) | StS는 층마다 3-4종 = 총 10+ 보스. **3배 부족** |
| **스토리/세계관** | GameDesign.md에 "TODO" 상태 | Griftlands/BG3/Persona는 스토리가 핵심. Team Log는 거의 부재 |
| **클리어 후 콘텐츠** | 어센션, 데일리 룬, 도전과제 모두 부재 | StS(어센션 20), Hades(열기 32), Balatro(스테이크 8) 대비 **0%** |
| **연출/일러스트** | 텍스트 위주, 배경 이미지도 미연결 | Hades/Persona 5는 연출이 게임 자체. **격차 큼** |
| **캐릭터 수** | 8종 (StS 4캐릭 × 350카드 vs Team Log 8캐릭 × 32스킬) | 캐릭터당 스킬 4개 고정이라 빌드 다양성 낮음 |

### Opportunities (기회)

- **로그라이크 시장 성숙**: Balatro(2024)의 메가히트로 장르 관심 최고조
- **K-인디 게임 글로벌 주목**: Steam 그린라이트 통과 유리
- **데일리 런/리더보드**: 로컬이라도 구현 시 커뮤니티 형성 용이
- **파티 로그라이크 틈새**: 현재 시장에 StS식 파티 로그라이크 부재 → **독자적 포지션 가능**

### Threats (위협)

- **신작 로그라이크 쏟아짐**: 매월 신작 출시 → 차별화 없으면 매몰
- **밸런스 붕괴 리스크**: 이미 F1 사망 80% 문제 발생. 콘텐츠 추가 시 복잡도 ↑
- **장르 피로도**: "또 로그라이크?" 반응 가능성
- **개발 리소스**: 인디 규모에서 콘텐츠 양이 승부 → 인력 한계

### 2.1 장르별 핵심 차별화 요소

| **Inscryption** | 서사-카드-보드 융합, 다크 미스터리 | ❌ (장르 자체가 다름) |

| **BG3** | 환경 상호작용 + 동료 대화 + 선택의 무게 | ✅ 환경 지형 + 캐릭터 대화 |
| **Divinity OS2** | 환경 연쇄 (독+불=폭발) + 파티 스토리 | ✅ 환경 연쇄 (Team Log 키워드 시스템과 잘 맞음) |
| **Griftlands** | 협상/전투 토글 + 팩션 평판 | ⚠️ 부분 (평판만) |

### 2.2 공통 성공 요소 (명작 모두가 갖춘 것)

1. **명확한 코어 루프** (10초 안에 설명 가능) ✅ Team Log 보유
2. **학습 곡선** (초보자 → 숙련자까지 100시간+) ⚠️ Team Log는 튜토리얼만 있고 심화 없음
3. **메타 진행도 시각화** (다음 목표가 명확) ⚠️ Team Log는 메타 상점만 있음
4. **매 런 다른 경험** (시드 + 선택 + RNG) ✅ Team Log 보유
5. **클리어 후 새로운 목표** (어센션/도전과제/언락) ❌ Team Log **완전 부재**
6. **캐릭터/세계에 대한 감정적 투자** ❌ Team Log **완전 부재**
7. **연출력** (보스 등장, 결정타, 레벨업) ⚠️ Team Log 부분 보유

## 3. 콘텐츠 확장 로드맵 (우선순위별)

### 🥇 P0 — 차별화 강화 (즉시, 1~2주)

> 기존 시스템의 철학을 강화하는 방향. **Team Log만의 정체성 확립**.

#### P0-1. **캐릭터 스토리 조각 시스템** (Griftlands + Hades에서 영감)

**목적**: 8 캐릭터에 감정적 투자 유도. 런 종료 보상 확장.

**설계안**:
- 각 캐릭터마다 **스토리 조각 5~10개** (과거, 동기, 인간관계)
- 런 종료 시 캐릭터 1명을 골라 조각 1개 해금 (클리어/사망 불문)
- 해금한 조각은 타이틀 화면 "아카이브"에서 열람
- 특정 조각 모두 해금 시 **히든 스토리** + 특수 스킨/컬러

**개발 비용**: 중간 (데이터 + UI)
**기대 효과**: 🔥🔥🔥 (리텐션 핵심, 팬덤 형성)
**기존 충돌**: 없음 (신규 시스템)

#### P0-2. **보스 풀 3종 → 12종 확장** (StS에서 영감)

**목적**: 매 런 보스가 다르게. 현재 3종은 81 테마 조합 대비 빈약.

**설계안**:
- 12 테마 각각 전용 보스 1종 (현재 3종 재사용 → 12종 분화)
- 보스마다 **고유 기믹** 1개 (소환/흡혈/빙결/폭발 등 테마 키워드 연계)
- 보스별 페이즈 1개 추가 (페이즈 2는 HP 50%에서 전환)
- DataGenerator 확장으로 에셋 자동 생성

**개발 비용**: 중간 (데이터 중심, 코드는 GetFloorScaling 재사용)
**기대 효과**: 🔥🔥🔥 (재플레이성 직격)
**기존 충돌**: BalanceSimulator 보스 풀 확장 필요

#### P0-3. **어센션 시스템** (StS + Hades에서 영감)

**목적**: 클리어 후 돌아올 이유. 장기 리텐션 핵심.

**설계안**:
- 어센션 1~15 (StS 20, Hades 32에서 절충)
- 각 어센션마다 **작은 modifier** 1개 (예: A1 적 HP+5%, A2 시작 골드 -10, A3 리롤 -1회)
- 누적 적용 (A5 = A1~A5 효과 합)
- 메타 강화와 별개 (유저 선택)
- 업적 시스템과 연계

**개발 비용**: 낮음 (데이터 + GameRunState 확장)
**기대 효과**: 🔥🔥🔥🔥 (가성비 최고)
**기존 충돌**: 없음

#### P0-4. **Daily Run 시드 시스템** (StS + Hades에서 영감)

**목적**: 매일 새로운 도전. 커뮤니티 형성.

**설계안**:
- 매일 자정(또는 정오) 시드 갱신 (날짜 기반 해시)
- 같은 날 전 세계 동일한 맵/적/유물/이벤트
- 로컬 리더보드 (점수 = 클리어 턴 수 + 잔여 HP + 골드)
- 매일 다른 modifier (예: "오늘은 모든 스킬 Cost +1, 대신 시작 AP +2")

**개발 비용**: 중간 (시드 시스템 + UI)
**기대 효과**: 🔥🔥🔥 (커뮤니티 리텐션)
**기존 충돌**: Random 시드 통제 필요 (현재 `UnityEngine.Random` 사용)

### 🥈 P1 — 재미 확장 (1~2개월)

> 전투/전략의 깊이를 늘리는 방향.

#### P1-1. **파티 관계 시스템** (Darkest Dungeon 2에서 영감) ⭐ Team Log 핵심 차별화

**목적**: "파티 조작" 컨셉 강화. Team Log만의 고유 시스템.

**설계안**:
- 두 캐릭터 간 **관계 레벨** (-3 적대 ~ +3 혈맹)
- 휴식 노드/이벤트에서 관계 변화 (공동 경험, 대화 선택)
- 관레벨 따라 보너스/패널티:
  - +3 혈맹: 둘 다 살아있으면 매 턴 ATK +1 / 쉴드 +3
  - -3 적대: 둘 다 살아있으면 매 턴 HP -1 (스트레스)
- 캐릭터 4명 = 관계 6쌍 (C(4,2) = 6) → 파티 구성의 새로운 차원

**개발 비용**: 높음 (시스템 + UI + 밸런스)
**기대 효과**: 🔥🔥🔥🔥🔥 (완전한 차별화)
**기존 충돌**: BalanceSimulator 관계 시뮬레이션 추가 필요

#### P1-2. **스킬 강화 분기 트리** (StS + Monster Train에서 영감)

**목적**: 같은 스킬이라도 빌드에 따라 다르게 진화.

**설계안**:
- 현재 SkillInstance.UpgradeLevel은 단순 +N
- 휴식지 강화 시 **3-way 분기** 선택:
  - 경로 A: 위력 +30%
  - 경로 B: Cost -1
  - 경로 C: 상태이상 부가 (예: 화염 추가)
- 같은 스킬이 전사 빌드/마법사 빌드/퓨어 딜 빌드로 분화

**개발 비용**: 중간
**기대 효과**: 🔥🔥🔥 (빌드 다양성)
**기존 충돌**: SkillInstance 구조 변경 → 저장 포맷 호환 필요

#### P1-3. **업적/통계 시스템** (모든 명작 공통)

**목적**: 메타 진행도 시각화 + 자긍심.

**설계안**:
- 100+ 업적 (캐릭터별 클리어 / 무피 클리어 / N턴 이내 / 특정 유물 조합)
- 통계: 총 플레이 시간 / 총 런 / 승률 / 보스 처치 수 / 총 획득 골드
- 타이틀 화면에서 확인

**개발 비용**: 낮음
**기대 효과**: 🔥🔥 (리텐션 보조)
**기존 충돌**: 없음

#### P1-4. **챌린지 모드** (Hades + StS에서 영감)

**목적**: 숙련자용 도전 콘텐츠.

**설계안**:
- 제약 조건 런: "리롤 금지" / "스킬 Cost 3이상 금지" / "유물 1개만" / "파티 3명"
- 클리어 시 업적 + 메타 재화 보너스
- 일일 챌린지와 조합 가능

**개발 비용**: 낮음
**기대 효과**: 🔥🔥 (숙련자 리텐션)
**기존 충돌**: 없음

### 🥉 P2 — 심화 (3~6개월)

#### P2-1. **환경 지형 시스템** (Divinity OS2 + Into the Breach에서 영감)

**목적**: 전투의 전술적 깊이. 현재는 "단순 스킬 교환".

**설계안**:
- 전장에 **지형 타일** 존재: 화염/빙결/독/물/장판
- 스킬이 지형에 영향:
  - 얼음 스킬 → 빙결 타일 생성 → 적이 밟으면 기절 확률
  - 화염 스킬 → 화염 타일 → 매 턴 도트 데미지
  - 독 + 화염 = 폭발 (연쇄)
- 일부 적이 지형 활용 (예: 화염 정령은 화염 타일에서 회복)

**개발 비용**: 매우 높음 (전투 씬 재설계)
**기대 효과**: 🔥🔥🔥 (전술성 대폭 강화)
**기존 충돌**: 전투 UI 전면 개편 필요

#### P2-2. **보스 페이즈 2-3** (Hades + Persona 5에서 영감)

**목적**: 보스전의 극적 클라이맥스.

**설계안**:
- 보스 HP 50%에서 페이즈 2 (패턴 변화, 기믹 추가)
- 최종 보스는 HP 33%/66%에 페이즈 2/3
- 페이즈 전환 시 연출 + 대사

**개발 비용**: 중간 (보스 AI + 연출)
**기대 효과**: 🔥🔥🔥 (기억에 남는 순간)
**기존 충돌**: EnemyAIController 확장

#### P2-3. **팩션/평판 시스템** (Griftlands에서 영감)

**목적**: 런 내 선택이 런 전체에 영향.

**설계안**:
- 3-4 팩션 (고블린 부족 / 언데드 연합 / 마왕군 / 인간 왕국)
- 이벤트 선택, 상점 이용, 적 처치가 평판에 영향
- 평판에 따라:
  - 우호적: 상점 할인, 유물 선물, 일부 적 비적대화
  - 적대적: 강화된 적, 매복 이벤트, 보스 강화

**개발 비용**: 중간 (데이터 + 밸런스)
**기대 효과**: 🔥🔥🔥 (선택의 무게)
**기존 충돌**: 이벤트 시스템 확장 (이미 Phase E 기반 있음)

#### P2-4. **캐릭터 개인 퀘스트** (BG3 + Persona에서 영감)

**목적**: P0-1 스토리 조각의 심화 버전.

**설계안**:
- 각 캐릭터 **개인 퀘스트 라인** 3~5개 챕터
- 런 중 특정 조건 (예: 같은 파티에서 N번 전투, 특정 보스 격파) 시 개인 이벤트 발생
- 완료 시 해당 캐릭터 **고급 특성 / 스킨 / 스토리 엔딩** 해금

**개발 비용**: 높음 (스토리 작성 + 이벤트 설계)
**기대 효과**: 🔥🔥🔥🔥 (감정적 투자)
**기존 충돌**: 없음 (신규 시스템)

### 🏆 P3 — 장기 확장 (6개월~)

#### P3-1. **스토리 캠페인 모드** (Griftlands + Persona에서 영감)

**목적**: 로그라이크 외에 서사형 모드.

**설계안**:
- 10장 분량의 메인 스토리
- 정해진 파티/적/이벤트
- 엔딩 3~5개 분기
- 클리어 시 로그라이크 모드의 추가 콘텐츠 해금

**개발 비용**: 매우 높음 (스토리 + 레벨 디자인)
**기대 효과**: 🔥🔥🔥🔥 (캐주얼 유저 유입)

#### P3-2. **로컬 멀티플레이어** (Divinity OS2에서 영감)

**목적**: 2인 협동 런.

**설계안**:
- 파티 4명을 2인이 2명씩 분담
- 각자 자기 캐릭터 스킬만 시전
- 리롤/AP는 공유 → 협의 필요

**개발 비용**: 매우 높음 (네트워크/입력 시스템)
**기대 효과**: 🔥🔥 (틈새 수요)
**기존 충돌**: 전투 씬 전면 개편

#### P3-3. **모드 지원** (StS + Hades에서 영감)

**목적**: 커뮤니티 주도 콘텐츠 확장.

**설계안**:
- 커스텀 캐릭터/스킬/유물/적/이벤트 에디터
- Steam 창작마당 연동
- 공식 서버에서 인기 모드 큐레이션

**개발 비용**: 매우 높음 (에디터 + API)
**기대 효과**: 🔥🔥🔥🔥🔥 (StS/Balatro 모드가 수명 5년+ 연장)

#### P3-4. **어빌리티 트리/특성 진화** (Hades + Diablo에서 영감)

**목적**: 메타 진행도의 시각화.

**설계안**:
- 현재 30종 메타 강화를 트리 형태로 재구성
- 분기점 (하나 선택하면 다른 건 포기)
- 특정 빌드(화염 특화/쉴드 특화/도박 특화) 시각화

**개발 비용**: 중간
**기대 효과**: 🔥🔥 (메타 진행도 직관화)

## 6. 리스크 분석

### 6.1 기술적 리스크

| 항목 | 리스크 | 완화책 |
|------|--------|--------|
| BalanceSimulator 한계 | 신규 시스템(관계/환경/어센션) 시뮬레이션 누락 → 밸런스 튜닝 불가 | 각 P0/P1마다 시뮬레이터 업데이트 병행 |
| 저장 포맷 호환성 | 스킬 분기/어센션 추가 시 기존 세이브 깨짐 | 버전 태그 + 마이그레이션 코드 |
| 전투 씬 복잡도 | 환경 지형 시 전투 UI 재설계 필요 | P2-1은 P3로 미루는 것도 검토 |

### 6.2 기획적 리스크

| 항목 | 리스크 | 완화책 |
|------|--------|--------|
| **정체성 희석** | 너무 많은 것을 추가하면 "Team Log만의 것"이 사라짐 | P1-1 관계 시스템을 **단일 차별화 축**으로 고정 |
| 밸런스 붕괴 | 어센션/팩션 추가 시 81 조합 × N = 밸런스 복잡도 폭발 | 각 modifier는 독립 적용 (누적 X) |
| 스토리 품질 | 캐릭터 스토리 빈약하면 오히려 마이너스 | 외부 작가 영입 or 양보다 질 |
| 콘텐츠 양 vs 인력 | 인디 규모에서 StS급 카드 350종 불가능 | **절대 카드 수로 승부하지 말 것**. 시너지/스토리로 승부 |

### 6.3 시장 리스크

| 항목 | 리스크 | 완화책 |
|------|--------|--------|
| 장르 포화 | 매월 신작 로그라이크 출시 | "파티 기반" + "드로우" 정체성 강조 |
| K-인디 경쟁 | 한국 인디 씬 성장 → 경쟁 심화 | 글로벌 타겟 (영어/일어 번역 예산 확보) |
| 트렌드 변화 | 발로란트식 라이브 서비스 유행 | 로그라이크 정체성 유지 (PvP 회피) |

## 8. 차별화 전략 (가장 중요)

### 8.1 "Path Less Traveled" — Team Log만의 길

**남들이 안 하는 것**을 할 때 인디 게임은 성공합니다:

| 남들 与 | Team Log 차별화 |
|---------|-----------------|
| 단일 영웅 (StS/Balatro) | **4인 파티 + 드로우** (시장에 거의 부재) |
| 보스 = 적 HP 높임 | **페이즈 + 기믹 + 런 영향** (매 런 보스가 다름) |
| 카드 수로 승부 | **시너지 루프 + 관계 시스템으로 승부** |
| 스토리 부재 | **8 캐릭터 개인 서사 + 팩션 평판** |
| 그냥 어려운 난이도 | **학습 곡선 + 어센션으로 점진적 난이도** |

### 8.2 핵심 메시지 (이거 하나만 기억하세요)

> **"Slay the Spire의 깊이 + Darkest Dungeon의 관계 + Hades의 스토리 분사를, 4인 파티 드로우 로그라이크에 담았다."**

이 한 줄이 마케팅 카피가 될 수 있어야 합니다.

## 9. 결론 및 다음 단계

### 즉시 시작할 것 (이번 주)
1. **P0-3 어센션 시스템** — 가성비 최고, 기존 시스템과 충돌 없음
2. **P1-3 업적/통계** — 사용자에게 진행도 시각화

### 다음 분기 집중
3. **P0-1 스토리 조각** — 외주 작가 섭외 검토
4. **P0-2 보스 다양성** — DataGenerator 확장
5. **P1-1 파티 관계 시스템** 설계 구체화 (이게 차별화 핵심)

### 신중할 것
- **P2-1 환경 지형**: 큰 효과지만 전투 씬 재설계 필요. 정식 출시 후 업데이트도 OK
- **P3-2 로컬 멀티**: 인디 규모에서 무리. 수요 검증 후 결정
- **P3-3 모드 지원**: 출시 후 6개월+는 지나야 검토

### 절대 하지 말 것
- **카드 350종 만들기**: 인디 규모에서 불가능 + 정체성 희석
- **PvP 모드**: 로그라이크와 안 맞음 + 밸런스 지옥
- **모바일 동시 출시**: UI 재설계 필요. PC 먼저 성공 후 포팅
