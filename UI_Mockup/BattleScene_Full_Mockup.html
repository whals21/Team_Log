📋 v3 변경사항 (2가지)

① 초상화 영역 미리 확보 적 패널(60px) + 플레이어 슬롯(50px)에 점선 테두리로 초상화 영역 명시.
"초상화" 라벨 표시 → 나중에 Sprite 에셋 교체 예정임을 시각적으로 명확히.
배경색 #0d1525로 일반 슬롯 배경과 구분.
② 캐릭터↔스킬 슬롯 수직 정렬 하단을 5컬럼 그리드 (4 슬롯 + 우측 130px)로 통일.
행 1: [캐릭1][캐릭2][캐릭3][캐릭4][AP 영역]
행 2: [스킬1][스킬2][스킬3][스킬4][리롤/턴종료]
캐릭터 슬롯과 스킬 슬롯이 같은 컬럼 너비로 수직 정렬 → 깔끔한 시각적 대응.
