## 3. 상세 작업 계획

### 🔴 P0-1: 적 AI 가중치 룰렛 다양화

**문제**: 가중치 30/25/25/20 편중 + 상황 규칙 단순 → 3번 싸우면 80% 동일 스킬 순서

**해결안** (StS 표준 적용):
1. **연속 사용 패널티** — 직전에 사용한 스킬 가중치 -10
2. **상황 규칙 확대** — HP 70%/50%/30% 단계별 + 아군 수 감소 시 힐 강화
3. **기본 가중치 균등화** — 모든 스킬 25로 시작, 상황으로만 차별화

**수정 파일**:
- `Assets/02.Scripts/Combat/AI/EnemyActionPattern.cs` — GetNextSkill, CalculateEffectiveWeight
- (옵션) `Assets/03.Data/Tables/EnemyPatternTable.csv` — 가중치 균등화

**검증**: 시뮬레이터에서 같은 적 10번 싸웠을 때 스킬 분포 분산도 확인

**예상 코드량**: ~50줄

---

### 🔴 P0-2: 스폰 패턴 랜덤화

**문제**: SpawnPatternTable SO 기반 단일 패턴 → 같은 노드는 항상 같은 적 조합

**해결안**:
1. `SpawnPatternTable`에 패턴 배열 (3-5종) 추가
2. 매 전투 시작 시 무작위 패턴 선택
3. 파워 합(EstimatedPower)으로 밸런스 유지

**수정 파일**:
- `Assets/02.Scripts/Map/SpawnPatternTable.cs` (또는 유사)
- `Assets/03.Data/SpawnPatterns/SpawnPatterns_F1~4.asset`
- `BalanceSimulator.Combat.cs` — CreateEnemiesFor 업데이트

**검증**: 같은 노드 5회 진입 시 적 조합 변화 확인

**예상 코드량**: ~80줄 + 데이터 작업

### 🔴 P0-3: 전투 튜토리얼 3단계 인액티브 가이드

**문제**: 전투 튜토리얼 3줄 텍스트만 → 새 플레이어 5분 내 포기 위험

**검증**: 첫 전투 플레이 시 가이드 따라 진행되는지 확인

**예상 코드량**: ~150줄
