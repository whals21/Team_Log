### 핵심 인사이트 (CLAUDE.md/MEMORY.md 반영)
10. **XML doc 주석(`///`)에 유니코드 박스 그리기 문자(`│├└─`) 사용 금지** — 줄마다 `///` 접두사가 빠지면 C# 파서가 코드로 잘못 해석하여 CS1056 "Unexpected character" 에러 폭발. 줄 단위 주석(`//`)은 문제없지만 XML doc(`///`)은 위험. → 주석은 단순한 텍스트(`-`, `*`)로 작성 권장.
11. **`UIAutoBindHelper.EnsureLayoutElement` 파라미터 이름** — `flexW`/`prefW`/`flexH`/`prefH` (짧은 형식). `flexibleWidth`/`preferredHeight` 아님. 새 Builder 작성 시 기존 호출부 참조 필수.
12. **`EventType` enum 이름 충돌 (UnityEngine vs TeamLog.Event)** — UnityEngine.EventType(IMGUI용)과 TeamLog.Event.EventType이 같은 이름. `using TeamLog.Event` + `using UnityEngine` 동시 사용 시 모호 → 정규화된 `TeamLog.Event.EventType` 사용 권장. 기존 프로젝트에서 EventData/EventManager가 이미 같은 이름 사용 중.
13. **Resources.Load는 `Assets/Resources/` 하위만 검색** — `Assets/03.Data/Events/` 에셋은 로드 안 됨. 연쇄 이벤트 같은 런타임 에셋 참조는 (a) Resources 폴더로 이동, (b) `_allEvents` 풀 인스펙터 주입, (c) Addressables 도입 중 하나로 해결. 본 프로젝트는 (b) 선택 — Builder가 AssetDatabase.FindAssets로 자동 주입.
14. **서브에이전트(code-explorer + code-reviewer) 병렬 패턴 정착** — 복잡한 UI 시스템 구현 시 (a) code-explorer로 기존 패턴 정밀 분석 → (b) 메인 에이전트가 코드 작성 → (c) code-reviewer로 P0 버그 사전 차단. AI 비전 추측보다 훨씬 정확. CLAUDE.md 가드레일 준수도 자동 검증.
