# 2026-06-16 작업 일지

## 작업 개요
Phase 5E(전투 밸런스 재설계)에서 적용한 큰 변경(드로우 가중치 통일, 적 스킬 +20%, 스폰 +1마리, 보스 HP +15%)을 객관적으로 검증하기 위한 **자동 밸런스 시뮬레이터(BalanceSimulator)** 구현. 이후 모든 밸런스 변경의 객관적 기준점 역할.

## 구현 내용

### 파일 구조 (partial class 4분할, `TeamLog.Editor` 네임스페이스)

| 파일 | 역할 | 줄 수 |
|------|------|------|
| `BalanceSimulator.cs` | 진입점 + 상수 + 메뉴 3종 + 에셋 로드 + 진행률 바 | ~210 |
| `BalanceSimulator.Combat.cs` | SimulatedPlayerAI (private 중첩) + Quick Combat 1000팩 + RunSingleCombat | ~480 |
| `BalanceSimulator.Run.cs` | Full Run 100회 + 맵 노드 자동 결정 + RunSingleRunWithState | ~470 |
| `BalanceSimulator.Report.cs` | ReportUtils 중첩 + 통계 집계 + CSV + 콘솔 요약 | ~250 |

### 메뉴 (TeamLog/Balance/)
- `Quick Combat (1000 packs)` — 9카테고리 매트릭스 (F1~F3 일반/엘리트/보스)
- `Full Run (100 runs)` — GameRunState 격리 + 맵 자동 진행
- `Run All (Quick + Full)` — 두 시뮬레이션 연달아 실행

모든 메뉴는 `Application.isPlaying` 가드 + `EditorUtility.DisplayCancelableProgressBar` 취소 지원.

### Quick Combat 매트릭스 (1000팩)
- 기본 파티: 전사 + 마법사 + 치유사 + 도적 (매 팩 새 인스턴스)
- F1 일반 200 + F1 엘리트 100 + F1 보스 100
- F2 일반 150 + F2 엘리트 100 + F2 보스 100
- F3 일반 100 + F3 엘리트 50 + F3 보스 100
- 적 생성: `SpawnPatternTable.RollNormalPattern/RollElitePattern` + 층별 스케일링(1.0/1.3/1.6)
- 보스: `new Character(bossData)` + ApplyFloorScaling

### SimulatedPlayerAI 휴리스틱
턴 루프: 리롤 평가 → 슬롯 평가 → 최고점 시전 → 반복 → 적 PrepareNextAction → ConfirmActions

| 스킬 타입 | 점수 |
|-----------|------|
| Heal HP<30% | 95 / HP<50% 85 / 불필요 20 |
| Shield 적 위협+HP<50% | 75 |
| Attack 처결 가능 | 90 / 일반 50+power/5 |
| Buff turn==1 | 80 / 그 외 40 |
| Debuff 위협적 적 | 60 |
| Purify 해로운 상태이상 | 70 |

코스트 효율 가산 `(3-cost)*2`. AP 부족 시 0점.

타겟 선택: SingleEnemy = 처결가능 > 위협 intent > 최저HP / SingleAlly(Heal) = 최저HP / SingleAlly(Buff) = 최고ATK

### Full Run 정책 (100회)
- 맵 경로: `avgHP<0.4` 위기시 Rest>Shop>Event>Battle>Elite, 여유시 Elite>Battle>Event>Shop>Rest
- Battle/Elite: RunSingleRunWithState → 승리 시 RewardManager.GenerateRewards → ChooseBestReward (유물>T2+증강>일반증강>골드)
- Boss: 전투 → AdvanceToNextFloor (F3 보스 승리=런 클리어)
- Shop: 예산=골드 70%, 유물 우선 구매
- Event: Choices[0] 선택
- Rest: HP<50% → RestAtCampfire(0.3) / F1 → TrainAtCampfire / 그 외 → MeditateAtCampfire

### 측정 지표 + CSV 스키마
**QuickCombat CSV** (`Assets/09.Docs/BalanceReports/QuickCombat_타임스탬프.csv`)
```
ScenarioName,Category,Floor,EnemyName,Victory,TurnCount,AvgRemainingHP,Survivors
```

**FullRun CSV** (`Assets/09.Docs/BalanceReports/FullRun_타임스탬프.csv`)
```
RunIndex,RunCompleted,FloorReached,DeathLocation,TotalBattles,TotalTurns,FinalPartyHP,Survivors,GoldEarned,RelicsAcquired,AugmentsAcquired
```

콘솔 요약: 전체 승률, 평균 턴, 평균 잔여 HP, 카테고리별 승률, 클리어율, 사망 분포(층별/노드타입별), 층별 도달률.

## 안전장치
1. **무한 루프 방지**: `MAX_TURNS = 50` 초과 시 자동 패배 + `CombatEventBus.Clear()` + `DamageCalculator.ClearEvents()` + `SkillExecutor.ClearEvents()` 매 팩 명시적 호출
2. **GameRunState 싱글톤 정리**: Quick Combat은 Instance null (유물 효과 제외, null-safe), Full Run은 매 런 Create/Destroy
3. **Application.isPlaying 가드**: 플레이 모드에서 메뉴 실행 차단
4. **EnemyPatternData 폴백**: 에셋 못 찾으면 `enemy.Data.Skills` + 기본 가중치 25로 폴백
5. **EnemyAIController.PrepareNextAction() 명시 호출**: TurnManager가 적 턴 시작 시 `_nextSkill` 갱신 안 함 → 시뮬레이터가 ConfirmActions 직전에 모든 생존 적의 PrepareNextAction 호출
6. **CSV 디렉토리 보장**: `EnsureReportDir`에서 `Assets/09.Docs/BalanceReports/` 사전 생성
7. **파티 인스턴스**: 매 팩/런마다 `new Character(data)` (HP/상태이상 초기화)
