### P0-1: AugmentSelectPanel 씬 부재 시 증강 영구 손실 (95% 신뢰)

**원인**: MapSceneReworkBuilder는 ConfirmationDialog/AugmentSelectPanel을 빌드하지 않음 (이들은 레거시 MapSceneBuilder만 생성). FindComponentInScene이 null 반환 → WireField가 조용히 스킵 → ShopReworkView의 `_augmentSelectPanel == null`.

**치명 영향**: 증강 구매 시 `if (slot.ContentType == Augment && _augmentSelectPanel != null)` 분기 진입 불가 → PurchaseItem이 IsSold=true만 설정하고 증강은 어디에도 배정되지 않음 → **골드만 소모되고 증강 영구 손실**.

**해결**: ShopReworkView.cs에 `AutoAssignAugmentFallback(augment)` 폴백 메서드 추가. AugmentSelectPanel이 null이면 첫 번째 살아있는 파티원의 첫 번째 빈 슬롯(MaxAugments=3 미충족)에 자동 배정. 빈 슬롯 없으면 false 반환 (골드는 이미 소모됨 — 사용자에게 토스트로 경고).

### P2: IconText 기본값 빈 문자열로 (깜빡임 방지)

Builder.Wiring.cs의 IconText TMP `text = "✦"` → `text = ""` 로 변경. Setup 호출 전까지 빈 텍스트 표시로 초기 깜빡임 방지.

18. **비활성 부모 아래 자식 SetActive(true)는 무의미** — TitleLabel이 TopBar 자식이어서 TopBar 비활성화에 같이 안 보였던 문제. 자식 GameObject를 활성화하려면 부모도 활성이거나, 부모를 변경해야 함. StyleApplicator 패턴: 보조 UI(StatsLabel 등) 비활성화 전에 메인 UI(TitleLabel)를 다른 부모로 이동시키는 안전장치 필수.
19. **RectTransform 코드 할당이 안 먹힐 때 DestroyImmediate + 재생성** — 기존 GameObject의 anchoredPosition을 코드로 설정해도 씬에 반영 안 되는 경우 (숨겨진 drift/override). 이럴 때는 깔끔하게 삭제 후 새로 만드는 게 가장 확실. SetParent(canvasTransform, false) → 새 RectTransform → anchoredPosition 설정 순서.
20. **기존 씬 인플레이스 수정 패턴 정립** — Builder가 새 씬/Prefab 생성하는 대신, StyleApplicator가 기존 씬의 GameObject들을 검색해서 디자인만 변경. 씬 구조/인스펙터 참조를 100% 보존해야 할 때 사용. Map/Event/Shop은 새 Prefab 방식, Title은 인플레이스 방식 — 용도에 따라 선택.
21. **TMP SetAllDirty + ForceMeshUpdate로 Editor 빌드 강제** — Editor 모드에서 TMP가 빌드 안 되어 bounds.size=(0,0,0)이 되는 현상. SetAllDirty()로 모든dirty 플래그 설정 + ForceMeshUpdate()로 강제 빌드. Play 모드에서는 자동으로 빌드되지만 Editor 모드 디버깅 시 필수.
22. **ScreenSpaceOverlay의 z-order = sibling index** — z-position이 아니라 sibling 순서가 곧 렌더링 순서. SetAsLastSibling()이 맨 위, SetAsFirstSibling()이 맨 아래. UI가 다른 UI에 가려질 때 ReorderCanvasChildren 헬퍼로 강제 정렬.
23. **자간(characterSpacing)으로 짧은 부제를 긴 제목과 비슷한 폭으로** — "Dark Fantasy Roguelike" 20pt + characterSpacing 35 = "TEAM LOG" 96pt와 비슷한 가로 폭. 다크 판타지 고딕 톤에서 부제 자간 넓히는 디자인 트렌드 반영.
