## 설계 철학

### 왜 "조합 컨셉"인가?

개별 몬스터가 아무리 독특해도, **조합이 시너지를 만들 때 전투는 비로소 기억에 남는다**. 단순한 "슬라임 3마리 + 고블린 2마리" 같은 수량 조합은 플레이어에게 **우선순위 결단**을 요구하지 않는다. 각 몬스터를 따로 잡아도 되기 때문이다.

좋은 조합 컨셉은 플레이어에게 이런 질문을 던진다:

> "이번 턴에 누구를 먼저 잡아야 하고, 어떤 스킬을 아껴야 할까?"

이 문서는 그런 **딜레마 중심의 조합 설계**를 카탈로그화한다.

### 3가지 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **1. 시너지 파훼 가능성** | 모든 조합은 특정 플레이로 파훼할 수 있어야 함 (정답이 없는 조합은 밸런스 붕괴) |
| **2. 우선순위 강제** | 적어도 1~2개의 "이번엔 이 몬스터를 먼저 잡아야" 명확한 타겟이 존재 |
| **3. 학습 곡선** | F1은 기본 메커니즘 학습, F2는 조합 대응, F3은 복합 시너지 파훼로 단계적 난이도 상승 |

## 1. 시너지 메커니즘 분류

모든 조합은 다음 6가지 메커니즘 중 하나 이상에 기반한다.

### 1.1 역할 분담형 (Role Specialization)

**메커니즘**: 탱커 + 딜러 + 힐러 등 클래식 삼위일체. 각자 다른 역할을 수행.

```
[탱커] 어그로 흡수 ← [딜러] 뒤에서 폭딸
                 ↑
            [힐러] 탱커 유지
```

- **파훼**: 힐러나 딜러를 우선 암살 (탱커는 무력화해도 힐러가 살아있으면 의미 없음)
- **예시**: 엘리트 기사(탱커) + 악마 병사(딜러) + 고블린 주술사(힐러)
- **영감**: Final Fantasy 시리즈, Darkest Dungeon

### 1.2 상태이상 누적형 (Status Stack)

**메커니즘**: 한 몬스터가 상태이상을 잔뜩 걸고, 다른 몬스터가 그걸 역이용.

```
[버섯] Poison 3스택 ─┐
[슬라임] AcidSpit ────┤→ [인퀴지터] Judgment 폭딸 (상태이상 × 3)
[망령] Chill ────────┘
```

- **파훼**: 상태이상 부여자(버섯/슬라임)를 먼저 잡거나, 플레이어가 Purify로 정리
- **예시**: 독버섯 + 슬라임 + 인퀴지터 (새 특수 적)
- **영감**: Darkest Dungeon - Blight/Bleed 조합, Persona - Ailment 기반 All-Out Attack

### 1.3 시간/자원 압박형 (Resource Drain)

**메커니즘**: AP를 갉아먹거나, 턴을 지연시키거나, 힐러 자원을 고갈.

```
[크로노맨서] AP -2 ───→ 플레이어 스킬 1개 적게 사용
[폭파술사] 지뢰 설치 ──→ 2턴 뒤 강제 데미지
              ↓
        "시간이 없다"
```

- **파훼**: 자원 파괴자(크로노맨서)를 최우선 처결
- **예시**: 크로노맨서 + 폭파술사 + 가디안
- **영감**: Slay the Spire - Time Eater / Lagavulin, Bravely Default - BP

### 1.4 증식/소환형 (Multiplication)

**메커니즘**: 매 턴 적의 수가 늘어남. 시간이 지날수록 전장이 적으로 가득 참.

```
[레기온] 소환 ──→ 턴 1: 1마리 → 턴 2: 3마리 → 턴 3: 5마리
[마이토제] 분열 ─→ 턴 1: 1마리 → 턴 2: 2마리 → 턴 3: 4마리
```

- **파훼**: 소환사 본체를 우선 처결 (소환수 무시). 광역 딜 필수
- **예시**: 레기온 + 미라 + 박쥐, 또는 마이토제 단독
- **영감**: Slay the Spire - Reptomancer, Darkest Dungeon - Bone Bearer

### 1.5 역설형 (Paradox)

**메커니즘**: 플레이어의 강점이 약점이 되는 구조.

```
[도플갱어] 메테오 쓰면 → 같은 메테오를 되돌려받음
                ↓
        "강한 스킬을 아껴야 한다"
```

- **파훼**: 약한 스킬로 꾸준히 딜. 자원 관리 퍼즐
- **예시**: 도플갱어 + 그림자
- **영감**: Persona - 거울 적, Slay the Spire - Mimic

### 1.6 거리/위치형 (Position)

**메커니즘**: 전열/후열로 나뉘어 후열이 보호됨.

```
[해골 전사] 전열 탱킹 ← 방어
[해골 궁수] 후열 안전 → 딜
                ↓
        "Taunt 없으면 후열 못 잡음"
```

- **파훼**: Taunt로 후열 어그로 끌기, 또는 방어 무시 스킬 (Backstab)
- **예시**: 해골 전사 × 2 + 해골 궁수 × 2 (엘리트: 해골 대장 추가)
- **영감**: Darkest Dungeon - 위치 시스템, Final Fantasy Tactics

## 2. 기본 조합 패턴 (기존 21종 활용)

### F1 일반 — 튜토리얼 단계 (학습 목적)

#### 2.1 "초원의 무리" — 기본 타겟팅
```
슬라임 ×3 + 고블린 ×2
```
- **목적**: 플레이어에게 "위협적인 적을 먼저 잡기" 교육
- **시너지**: 슬라임(재생)은 버텨두면 힐됨 → 고블린(Opportunist)이 약한 아군 타격
- **정답**: 슬라임을 1~2마리 잡아 재생 카운트 줄이기 → 고블린 처리

#### 2.2 "독 포자 군단" — 상태이상 첫 경험
```
독버섯 ×3 + 슬라임 ×3
```
- **목적**: 독의 위협과 Purify의 가치 교육
- **시너지**: 버섯 Spore(독) + 슬라임 AcidSpit(약화) → 도트 누적
- **정답**: 버섯(Thorns)을 도트 없이 딜, 슬라임을 먼저 잡아 재생 차단

#### 2.3 "늑대 무리" — 물리 폭딜 경고
```
늑대 ×5
```
- **목적**: Counter 특성 경고. 다수 타격 시 반격 데미지 누적
- **시너지**: 각 늑대가 공격받을 때마다 3 고정 반격 → 도적 DoubleStrike 금지
- **정답**: 단일 강타 스킬로 한 마리씩 잡기

---

### F1 엘리트 — 첫 위기

#### 2.4 "암흑 슬라임 의식"
```
암흑 슬라임 ×1 + 독버섯 ×2
```
- **시너지**: 버섯이 독 걸고 암흑 슬라임(Corrosive)이 디벞을 방어 감소와 함께 누적
- **정답**: 버섯을 먼저 잡아 독 차단 → 암흑 슬라임에 물리 딜 집중

---

### F2 일반 — 조합 대응 학습

#### 2.5 "유적의 진형" — 거리/위치 첫 경험
```
해골 전사 ×2 + 해골 궁수 ×2
```
- **목적**: 전열 탱킹 + 후열 딜 구조 교육
- **시너지**: 전사(PhaseShift, DEF 버스트)가 버티는 동안 궁수가 안전 딜
- **정답**: 전사 Taunt로 궁수 어그로 끌기, 또는 도적 Backstab으로 궁수 암살

#### 2.6 "피의 원무곡" — 힐 레이스
```
박쥐 ×3 + 미라 ×1
```
- **시너지**: 박쥐 DrainLife(흡혈) + 미라 Bandage(힐) → 적 유효 DPS > 플레이어 DPS
- **정답**: 미라를 먼저 잡아 힐 차단 → 박쥐를 한 턴에 2마리씩 처결 (재생 전에)

---

### F2 엘리트 — 복합 시너지

#### 2.7 "해골 대장의 지휘" — 진형 강화
```
해골 대장 ×1 + 해골 궁수 ×2
```
- **시너지**: 대장 Warcry(전체 ATK 버프) + 대장 ShieldWall + 궁수 안전 딜
- **정답**: 대장을 CC(Stun)로 무력화 후 궁수 먼저 잡기, 또는 대장에게 도트 누적

---

### F3 일반 — 모든 메커니즘 종합

#### 2.8 "석양의 결사대" — 약점 카운터
```
가고일 ×2 + 악마 병사 ×2 + 그림자 ×1
```
- **시너지**: 가고일(Thorns, 물리 경감) + 악마(Counter, 마법 경향) + 그림자(Shell, 회피)
- **정답**: 각 약점을 찔러야 함. **파티 빌드 다각화 강제**

---

### F3 엘리트 — 미니 보스급

#### 2.9 "마왕군 정예 소대" — 삼위일체
```
엘리트 기사 ×1 + 악마 병사 ×2 + 고블린 주술사 ×1
```
- **시너지**: 기사 Taunt(탱킹) + 악마 폭딸 + 주술사 힐/버프
- **정답**: 주술사(힐) → 악마(딜) → 기사(탱) 순서. 또는 기사 Taunt 없는 턴에 주술사 암살

## 3. 특수 적 포함 조합 (새 컨셉)

> `MonsterCatalog.md` 섹션 5의 특수 적 7종이 등장하는 시나리오.
> 모두 **새로운 게임 메커니즘**을 도입.

### 3.1 "시공간의 함정" (F3 엘리트)

```
크로노맨서 ×1 + 폭파술사 ×1 + 가디안 ×1
```

| 메커니즘 | 시너지 |
|----------|--------|
| 가디안이 버티는 동안 | 시간 벌기 |
| 크로노맨서가 AP -2 | 플레이어 스킬 기회 박탈 |
| 폭파술사가 지뢰 설치 | 2턴 뒤 강제 데미지 |

**결과**: 3턴 뒤 **연쇄 폭발 + AP 고갈 → 강제 사망 타이머**

**파훼법**:
1. 1턴 차에 가디안을 CC(Stun)로 고정
2. 2턴 차에 크로노맨서 암살 (TemporalAnchor 부활 예상)
3. 3턴 차에 폭파술사 ChainReaction 전에 처결
4. 지뢰 설치된 아군은 쉴드/힐로 보호

**영감**: Slay the Spire - *Spire Shield + Spire Spear* (강제 시간제한)

---

### 3.2 "심판의 날" (F3 엘리트)

```
인퀴지터 ×1 + 독버섯 ×2 + 망령 ×2
```

| 메커니즘 | 시너지 |
|----------|--------|
| 버섯 Spore | 다수 독 부여 |
| 망령 Chill | 약화 누적 |
| 인퀴지터 Judgment | **상태이상 × 3 추가 데미지** → 폭딸 변신 |

**결과**: 플레이어 아군이 상태이상 5스택 시 Judgment로 **한 방에 처결당함**

**파훼법**:
1. 버섯을 최우선 처결 (상태이상 공급 차단)
2. 인퀴지터에게 **상태이상 걸지 않기** (Punisher로 역공 당함)
3. 치유사 Purify로 아군 상태이상 정리
4. 인퀴지터는 순수 딜로만 잡기 (Brand로 저주 걸면 더 위험)

**영감**: Darkest Dungeon - *Fanatic + 수하들* (테마적 압박)

---

### 3.3 "거울 미궁" (F3 특수 이벤트)

```
도플갱어 ×2 + 그림자 ×2
```

| 메커니즘 | 시너지 |
|----------|--------|
| 도플갱어 Echo | 플레이어 스킬 복사 |
| 도플갱어 Mirror | 마법 25% 반사 |
| 그림자 Shell | 첫 상태이상 무효 |
| 그림자 PhaseShift | 회피 버스트 |

**결과**: **강한 스킬 쓸수록 자기 파티가 삭제되는 역설**. 메테오 쓰면 도플갱어가 같은 메테오를 쏨.

**파훼법**:
1. **마법사는 약한 스킬만 사용** (IceSpear 대신 기본 공격)
2. 물리 딜러(전사/도적)가 주력
3. 도적 Backstab으로 Echo 쓰기 전에 암살
4. 도플갱어가 Echo 직전이면 가장 약한 스킬을 의도적으로 사용 → 복사 데미지 최소화

**영감**: Persona 5 - *거울의 적* (자기 파티 능력 역이용)

---

### 3.4 "군단의 밤" (F2 엘리트 / F3 보스 대체)

```
레기온 ×1 + 미라 ×1 + 박쥐 ×2
```

| 메커니즘 | 시너지 |
|----------|--------|
| 레기온 RaiseHorde | 매 턴 스켈레톤 2체 소환 |
| 미라 Bandage | 소환수 힐 (유지) |
| 박쥐 DrainLife | 흡혈로 장기전 버팀 |

**결과**: **무한 좀비 웨이브**. 시간이 갈수록 전장이 적으로 가득 참.

**파훼법**:
1. **레기온 본체 우선 처결** (Commander 때문에 소환수 잡으면 오히려 강해짐)
2. 미라는 두 번째 우선순위 (힐 차단)
3. 박쥐는 무시 (약함)
4. 레기온 암살 후 소환수 정리 (광역 딜)

**영감**: Slay the Spire - *Reptomancer + Daggers* (소환사 + 수하들)

---

### 3.5 "불멸의 군대" (F3 엘리트 하드)

```
가디안 ×1 + 크로노맨서 ×1 + 고블린 주술사 ×1
```

| 메커니즘 | 시너지 |
|----------|--------|
| 가디안 석벽 | 쉴드 + 방어 형태 (받는 딜 -50%) |
| 크로노맨서 시간 역행 | 가디안 HP 회복 |
| 주술사 힐/버프 | 가디안 유지 |

**결과**: **사실상 무한 전투**. 시뮬레이터 MAX_TURNS=50 패배 위험.

**파훼법**:
1. **가디안에게 절대 도트 걸지 말 것** (AdaptiveArmor로 저항 증가)
2. 물리/마법 교대 딜로 AdaptiveArmor 무력화
3. 크로노맨서를 1순위 처결 (가디안 힐 차단)
4. 주술사를 2순위 (남은 버프 차단)
5. LastStand(HP 30%) 전에 가디안을 40% → 0%로 한 번에 처결

**영감**: Final Fantasy - *Weapon* 보스전 (다층 방어 체계)

---

### 3.6 "증식함" (F3 특수 보스)

```
마이토제 ×1 (단독)
```

| 턴 | 개체 수 | 총 HP 풀 | 비고 |
|----|---------|---------|------|
| 1 | 1 | 80 | 단일 — 폭딜 기회 |
| 2 | 2 | 80 (분할) | 각 40씩 |
| 3 | 4 | 80 (분할) | 각 20씩 |
| 4 | 8 | 80 (분할) | 각 10씩 — 이 시점부터 통제 불가 |

**결과**: 총 HP는 같지만 **공격 횟수가 지수 증가**. 4턴 이상 버티면 사실상 패배.

**파훼법**:
1. **1~2턴 안에 본체를 한 번에 처결** (단일 폭딜)
2. 실패 시 3턴부터는 광역 딜(Meteor/Chain Lightning급)로 다수 처결
3. **도트(Poison/Burn)가 핵심** — 모든 개체에 적용되어 Regenerative 봉쇄
4. Stun/Freeze로 분열 차단 (Mitosis를 쓰지 못하게)

**영감**: Slay the Spire - *Spire Growth / Specimen*, SCP Foundation - SCP-017

### 3.7 "마왕의 친위대" (F3 최종 보스 강화판)

```
마왕 ×1 (본체) + 악마 마법사 ×1 + 인퀴지터 ×1
```

| 메커니즘 | 시너지 |
|----------|--------|
| 마왕 Immortal | HP 0 → 1 생존 (1회) |
| 악마 마법사 Hellfire | 광역 폭딸 |
| 인퀴지터 Judgment | 저주 건 대상에게 폭딸 |

**결과**: 보스전의 **진정한 종합 시험**. 모든 메커니즘이 한 자리에.

**파훼법**:
1. **인퀴지터를 1순위** (Judgment로 아군 삭제되기 전에)
2. 악마 마법사를 2순위 (광역 딜 차단)
3. 마왕은 LastStand 없으니 Immortal 턴 (HP 1)만 고려하면 됨
4. 마왕 Immortal 발동 후 1턴 안에 마무리 (HP 1이므로 한 대만 때리면 됨)

**영감**: Final Fantasy - *카오스*, Slay the Spire - *Corrupt Heart* (최종 종합 시험)

## 5. 밸런스 가이드라인

### 5.1 시뮬레이터 승률 목표

| 조합 | 난이도 | Quick Combat 목표 승률 |
|------|--------|----------------------|
| F1 일반 | 쉬움 | 85~95% |
| F1 엘리트 | 보통 | 70~80% |
| F1 보스 | 보통 | 60~75% |
| F2 일반 | 보통 | 75~85% |
| F2 엘리트 | 어려움 | 55~70% |
| F2 보스 | 어려움 | 50~65% |
| F3 일반 | 어려움 | 65~75% |
| F3 엘리트 | 매우 어려움 | 40~55% |
| F3 보스 | 매우 어려움 | 30~50% |
| F3 특수 (증식함 등) | 최난이도 | 20~35% |

### 5.2 Full Run 목표

- **클리어율**: 25~45% (Slay the Spire Ascension 0 기준 50% 전후)
- **사망 분포**: F1 < F2 < F3 (층이 올라갈수록 사망 증가)
- **특수 적 등장 빈도**: 전체 전투의 15~25% (너무 자주 나오면 피로, 너무 드물면 임팩트 없음)

### 5.3 특수 적 밸런스 원칙

1. **새 특성은 단일 적에만 부여**: 여러 적이 같은 특성 가지면 파훼법이 중복 적용되어 쉬워짐
2. **강력한 메커니즘은 약점 명확히**: 예) 마이토제 분할은 강하지만, 도트+광역 조합에 약함
3. **조합 시너지는 파훼 가능**: 모든 시너지는 적어도 2가지 파훼법 존재 (정답이 아닌 전략 다양성)
4. **한 조합당 새 메커니즘 1개 이하**: 한 전투에 2개 이상 새 메커니즘 겹치면 인지 과부하

## 7. 구현 우선순위

> 새 몬스터 7종 + 새 특성 7종은 설계만 완료된 상태. 구현은 다음 순서로 진행 권장.

### Phase 6A (쉬운 구현 우선)

1. **인퀴지터** + Punisher 특성
   - 기존 상태이상 시스템(14종) 활용 → 새 메커니즘 추가 불필요
   - Judgment 스킬의 "상태이상 × N" 로직만 DamageCalculator에 추가
   - 영향: 상태이상 기반 파티의 메타 카운터

2. **가디안** + AdaptiveArmor 특성
   - 모드 전환(방어/공격 형태)은 버프 시스템으로 처리 가능
   - 물리/마법 타입 구분만 DamageType enum 추가하면 됨
   - 영향: 파티 빌드 다각화 강제

### Phase 6B (중간 난이도)

3. **크로노맨서** + TemporalAnchor 특성
   - AP 디버프는 TurnContext에 필드 추가
   - TemporalAnchor는 Immortal과 유사하게 PreventDeath 훅 확장
   - 영향: AP 자원 메커니즘 확장

4. **마이토제** + Regenerative 특성
   - Mitosis 소환 시스템 필요 (전투 중 적 추가)
   - Regenerative는 Regenerate의 % 버전
   - 영향: 보스 대체 컨셉 가능

### Phase 6C (어려운 구현)

5. **폭파술사** + Trapper 특성
   - "지뢰 표식"은 새 상태이상으로 추가 필요 (MineMark)
   - 지연 폭발 타이머 로직 (TurnManager 훅)
   - 영향: 시간제한 전투 메커니즘

6. **레기온** + Commander 특성
   - 소환 시스템 전면 구현 (전투 중 적 리스트 동적 추가)
   - TurnManager가 적 리스트를 동적으로 처리해야 함
   - 영향: 다수 적 전투 메커니즘

7. **도플갱어** + Mirror 특성
   - 스킬 복사 시스템 (직전 플레이어 스킬 기록 → 복사 시전)
   - 복사 로직이 복잡, 모든 스킬 타입 대응 필요
   - 영향: 가장 독특하지만 구현 난이도 최상

### Phase 6D (조합 에셋)

8. SpawnPatterns_F1/F2/F3.asset에 새 패턴 추가
9. DataGenerator에 특수 적 7종 + 특성 7종 생성 코드
10. BalanceSimulator로 새 조합 승률 측정 → 밸런스 튜닝
