## CC-2G-5: Sibyl (Oracle) 리워크 — 신규 Behavior 3종

### 인프라 추가: HitThisTurn (Character/HealthComponent/TurnManager)

**Character.cs** (+5줄)
- `public bool HitThisTurn { get; private set; }`
- `MarkHitThisTurn()` / `ResetHitThisTurn()` 메서드

**HealthComponent.cs** (+2줄)
- `TakeDamage`의 HP 감소 블록 끝에 `_owner?.MarkHitThisTurn()` 추가
- `TakeDirectDamage`에도 동일 추가

**TurnManager.StartNewTurn** (+3줄)
- 매 턴 시작 시 모든 캐릭터(플레이어+적) `ResetHitThisTurn()` 호출

### 신규 Behavior 3종 (ConditionalBehaviors.cs "Phase CC-2G-5" 섹션)

**FollowUpBehavior** — PowerModify, Order=65
- `target.HitThisTurn == true` 시 +rank 위력
- 동작: 직전 스킬이나 동료 스킬이 이미 때린 적에게 보너스 (일점사 시너지)

**EchoBehavior** — PostApply, Order=50
- 메인 타겟에게 `CurrentPower / 2` 추가 데미지 (위력 절반 2회)
- DamageCalculator.DealDamage 직접 호출

**LimitBreakBehavior** — PowerModify, Order=80
- `UsesThisBattle == 0` (전투당 첫 사용)에서만 +rank 위력
- SkillInstance.UsesThisBattle 인프라 활용 — 이미 ARCH-5에서 구축됨

### 데이터 수정 (DataGenerator.PhaseCC.cs)
- Death Prophecy → `FollowUp(4)` — 이미 맞은 적에게 +4
- Vision of Renewal → `LimitBreak(8)` — 전투당 첫 힐 시 +8 (12→20)
- Déjà Vu → `Echo(0)` — 위력 절반 추가 (10+5=15)
- Borrowed Future — 변경 없음 (Buff라 LimitBreak 무의미하여 재배치)

**테스트 5개**
- FollowUp 발동/미발동 2개 + Echo 1개 + LimitBreak 첫/두 번째 사용 2개

## BattleDisplayUtil.GetBehaviorLabel — 신규 라벨 5종

- `FollowUp`: "이미 맞은 적 +N"
- `Echo`: "위력 절반 2회"
- `LimitBreak`: "전투당 1회 +N"
- `Explosion`: "전하 폭발 (스택×3)"
- `Momentum`: "사용 시 위력 +N 누적"
- `Fatigue`: "사용 시 위력 -N 누적" (백로그 대응)

## 핵심 설계 결정

1. **HitThisTurn 인프라**: Character에 간단한 bool 필드 추가로 FollowUp 추적. 매 턴 시작 시 리셋, HP 감소 시 true. CombatEventBus나 별도 매니저 대신 Character 자체에 두어 캡슐화.
2. **LimitBreak는 Heal에 재배치**: Buff 스킬은 CurrentPower가 무의미하여 AttackUp value에 영향 안 줌. Vision of Renewal(Heal)에 배치하여 힐량 증가로 직관적 효과.
3. **Momentum은 별도 Behavior 없이 SkillInstance만으로 작동**: ARCH-5 인프라 재활용. BehaviorTag만 추가하면 EffectivePower에서 자동 반영.
4. **Explosion DamagePerStack=3**: Taranis Charge 최대 3스택이므로 항상 +9로 고정. 밸런스 조정 시 상수 변경으로 간단.
5. **Echo는 PostApply에서 CurrentPower/2**: PowerModify로 증가된 최종 위력 기준. 재귀 호출 대신 DamageCalculator.DealDamage 직접 호출로 단순화.
