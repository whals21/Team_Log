## 설계 원칙

모든 특성은 다음 조건을 충족해야 함:

| 조건 | 설명 |
|------|------|
| 예측 가능 | 플레이어가 발동 조건을 인지하고 미리 대비 가능 |
| 파훼 가능 | 특정 전략으로 대응 가능 |
| 의사결정 변경 | 평소와 다른 플레이를 유도 |
| 발동이 체감 | 플레이어가 특성 발동을 인지 가능 |

## 1. 일반 적 특성 (6종)

### Regenerate — 재생

| 항목 | 내용 |
|------|------|
| 색상 | 청록 `rgb(26, 128, 128)` |
| 발동 타이밍 | 턴 시작 |
| 효과 | 턴 시작 시 HP 5 회복 |
| 조건 | Poison 또는 Burn 상태가 아닐 때만 발동 |
| 발동 제한 | 없음 (매 턴) |

**파훼법**: 독(Poison)이나 화상(Burn)을 걸면 재생 봉초. 도트 데미지 스킬의 가치가 상승.

**배정 적**: 슬라임 (Enemy_Slime)

**구현 훅**: `OnTurnStart()`

---

### Opportunist — 약자 노림

| 항목 | 내용 |
|------|------|
| 색상 | 빨강 `rgb(153, 38, 38)` |
| 발동 타이밍 | 타겟 선택 시 |
| 효과 | 항상 HP가 가장 낮은 파티원을 공격 |
| 특이사항 | Taunt(도발) 무시 |
| 발동 제한 | 없음 (매 공격) |

**파훼법**: 파티원 HP를 균등하게 유지하거나, 반대로 탱커가 일부러 피를 깎아 타겟을 유도. 힐러 턴 순서 조정으로 최저 HP 순환.

**배정 적**: 고블린 (Enemy_Goblin)

**구현 훅**: `EnemyAIController.SelectRandomAlivePlayer()`

---

### PhaseShift — 위상 변이

| 항목 | 내용 |
|------|------|
| 색상 | 파랑 `rgb(77, 77, 179)` |
| 발동 타이밍 | 턴 시작 |
| 효과 | 홀수 턴: DEF +4 / 짝수 턴: ATK +4 |
| 전환 | 매 턴 교대, 이전 보너스 자동 제거 |
| 발동 제한 | 없음 (매 턴) |

**파훼법**: 짝수 턴(공격 강화)에 방어/쉴드 준비, 홀수 턴(방어 강화)에 공격 집중. 턴 카운트를 세는 습관 필요.

**배정 적**: 해골 전사 (Enemy_Skeleton)

**구현 훅**: `OnTurnStart(turnNumber)`

---

### Counter — 반격

| 항목 | 내용 |
|------|------|
| 색상 | 주황 `rgb(179, 89, 26)` |
| 발동 타이밍 | 피격 시 |
| 효과 | 공격자에게 고정 3 데미지 반격 |
| 특이사항 | 반격 데미지는 DEF 무시 (고정) |
| 발동 제한 | 없음 (매 피격) |

**파훼법**: 단일 강타로 공격 횟수를 최소화, 또는 도트(Poison/Burn)로 우회 (도트는 피격이 아님). 쉴드로 흡수해도 반격은 발동하므로 주의.

**배정 적**: 늑대 (Enemy_Wolf)

**구현 훅**: `OnDamageReceived(attacker, damage)`

---

### Thorns — 가시

| 항목 | 내용 |
|------|------|
| 색상 | 녹색 `rgb(38, 140, 51)` |
| 발동 타이밍 | 피격 시 |
| 효과 | 받은 피해의 30%를 공격자에게 반사 |
| 계산 | `반사 데미지 = receivedDamage * 3 / 10` (정수 연산) |
| 특이사항 | 반사 데미지는 DEF 무시 |
| 발동 제한 | 없음 (매 피격) |

**파훼법**: 약한 공격으로 반사량 최소화, 도트로 우회, 또는 HP가 높은 탱커가 대신 맞음. 적 체력이 낮으므로 버스트로 한 턴에 잡는 것도 유효.

**배정 적**: 독버섯 (Enemy_Mushroom)

**구현 훅**: `OnDamageReceived(attacker, damage)`

---

### Shell — 껍질

| 항목 | 내용 |
|------|------|
| 색상 | 갈색 `rgb(128, 115, 89)` |
| 발동 타이밍 | 상태이상 적용 시 |
| 효과 | 매 턴 첫 번째 상태이상을 무효화 |
| 리셋 | 매 턴 시작 시 차단 횟수 초기화 |
| 발동 제한 | 1회/턴 |

**파훼법**: 의미 없는 상태이상을 먼저 걸어 Shell을 소모시킨 뒤, 핵심 상태이상을 두 번째로 걸기. 또는 상태이상 없이 순수 데미지로 상대.

**배정 적**: 박쥐 (Enemy_Bat)

**구현 훅**: `ShouldBlockEffect()` — TurnManager/EnemyAIController의 `ApplyEffect`에서 체크

## 2. 엘리트 특성 (3종)

### Sturdy — 견고

| 항목 | 내용 |
|------|------|
| 색상 | 강철 `rgb(102, 102, 128)` |
| 발동 타이밍 | 피격 시 |
| 효과 | 매 턴 첫 번째 공격 데미지 50% 감소 |
| 계산 | `finalDamage = damage / 2` (정수 나눗셈) |
| 리셋 | 매 턴 시작 |
| 발동 제한 | 1회/턴 |

**파훼법**: 약한 스킬이나 도트로 첫 타를 흘려보낸 뒤, 강한 스킬로 때림. 이중 타격(Rogue_DoubleStrike)은 1회 공격으로 처리되어 Sturdy를 효율적으로 소모.

**배정 적**: 정예 기사 (Enemy_EliteKnight)

**구현 훅**: `ModifyIncomingDamage(damage)`

---

### ArcaneFury — 마력 폭주

| 항목 | 내용 |
|------|------|
| 색상 | 보라 `rgb(102, 38, 153)` |
| 발동 타이밍 | HP 임계치 도달 시 |
| 효과 | HP 50% 이하가 되는 즉시 ATK +5 |
| 발동 제한 | 1회/전투 |

**파훼법**: 한 턴 안에 50% 이하로 깎고 바로 잡아냄(버스트), 또는 50% 직전에서 쉴드/힐 대비 후 깎기. 발동 후에 ATK가 영구 증가이므로 장기전 불리.

**배정 적**: 마법사 고블린 (Enemy_EliteMage)

**구현 훅**: `OnDamageReceived()` → `CheckThreshold(5)`

---

### Corrosive — 부식

| 항목 | 내용 |
|------|------|
| 색상 | 녹녹색 `rgb(77, 128, 38)` |
| 발동 타이밍 | 데미지를 입혔을 때 |
| 효과 | 피해를 입은 대상에게 DefenseDown 2턴 (DEF -2) 부여 |
| 특이사항 | 모든 공격에 자동 발동 |
| 발동 제한 | 없음 (매 피격) |

**파훼법**: 탱커(전사)가 Taunt로 데미지를 받아 방어감소를 한 곳에 집중시키거나, 반대로 분산시킴. DefenseDown이 겹칠 수 있으므로 장기전에서 파티 전체가 약해짐.

**배정 적**: 암흑 슬라임 (Enemy_EliteDarkSlime)

**구현 훅**: `OnDamageDealtTo(target)`

## 3. 보스 특성 (3종)

### Rally — 소집령

| 항목 | 내용 |
|------|------|
| 색상 | 금색 `rgb(179, 153, 26)` |
| 발동 타이밍 | HP 임계치 도달 시 |
| 효과 | HP 50% 이하 시 AttackUp 2턴 (ATK +8) + DefenseUp 2턴 (DEF +4) 동시 획득 |
| 발동 제한 | 1회/전투 |

**파훼법**: 임계점 전에 버스트로 한 턴에 50% 이하에서 완전히 잡아냄, 또는 발동 전 쉴드/힐 대비. 발동 시 ATK+DEF이 동시에 오르므로 잡기 더 어려워짐.

**배정 적**: 고블린 왕 (Enemy_BossGoblinKing)

**구현 훅**: `OnDamageReceived()` → 상태이상 `AttackUp` + `DefenseUp` 적용

---

### Rampage — 연소

| 항목 | 내용 |
|------|------|
| 색상 | 빨강 `rgb(179, 38, 26)` |
| 발동 타이밍 | 턴 시작 |
| 효과 | 이전 턴에 피해를 입지 않았으면 ATK +3 누적 |
| 초기화 | 피해를 입으면 누적 수치 0으로 리셋 |
| 발동 제한 | 없음 (매 턴 누적) |

**파훼법**: 매 턴 반드시 드래곤에게 데미지를 넣어 누적을 리셋. 쉴드 흡수는 피해로 간주하지 않으므로 실제 HP 데미지 필요. 파티 전체가 "이번 턴 누가 때릴지" 분배해야 함.

**배정 적**: 드래곤 (Enemy_BossDragon)

**구현 훅**: `OnTurnStart()` → `ApplyRampage()`, `OnDamageReceived()` → 피해 여부 기록

### Immortal — 불사

| 항목 | 내용 |
|------|------|
| 색상 | 진보라 `rgb(140, 26, 140)` |
| 발동 타이밍 | 치명적 피해 시 |
| 효과 | HP가 0이 되어야 할 때 HP 1로 생존 |
| 발동 제한 | 1회/전투 |

**파훼법**: 마지막 슬롯에 약한 스킬을 배치해 두 번째 킬을 확실히 넣을 수 있게 계획. 또는 원킬 이후 다음 턴에 마무리. HP 1에서 쉴드를 치면 더 귀찮아지므로 빠른 마무리가 핵심.

**배정 적**: 마왕 (Enemy_BossDemonLord)

**구현 훅**: `PreventDeath()` → HealthComponent의 `OnPreDeath` 이벤트에서 호출

## 4. 특수 적 특성 (7종)

> 특수 적 전용 메커니즘. `MonsterCatalog.md` 섹션 5의 7종 특수 적이 보유.
> 상세 설계는 `EncounterConcepts.md` 참조.

### TemporalAnchor — 시간 정점

| 항목 | 내용 |
|------|------|
| 색상 | 은빛 청록 `rgb(89, 179, 179)` |
| 발동 타이밍 | 치명적 피해 시 |
| 효과 | HP가 0이 되어야 할 때 **HP 30%로 부활** + 1턴 무적 |
| 발동 제한 | 1회/전투 |

**파훼법**: 부활 후 즉시 CC기(Stun/Freeze)로 무적 턴을 무의미하게 만들거나, 부활 직후 폭딜로 재끝냄. 한 번에 30% 이하로 깎고 다음 턴 마무리하는 "2킬 플랜" 필요.

**배정 적**: 크로노맨서 (Enemy_Chronomancer)

**구현 훅**: `PreventDeath()` → HP를 1이 아닌 30%로 설정 + 1턴 무적 버프

### Trapper — 함정술사

| 항목 | 내용 |
|------|------|
| 색상 | 진주황 `rgb(191, 89, 0)` |
| 발동 타이밍 | 사망 시 |
| 효과 | 사망 시 **자신이 설치한 모든 지뢰 자동 폭발** (위력 100%) |

**파훼법**: 폭파술사를 처결하기 전에 지뢰가 설치된 아군을 미리 벗겨내거나 쉴드/힐로 폭발에 대비. 또는 ChainReaction을 먼저 유도해 지뢰를 터뜨린 뒤 처결.

**배정 적**: 폭파술사 (Enemy_Saboteur)

**구현 훅**: `OnDeath()` → 활성 지뢰 전체 폭발 트리거

### Punisher — 처벌자

| 항목 | 내용 |
|------|------|
| 색상 | 황금 갈색 `rgb(128, 89, 0)` |
| 발동 타이밍 | 공격 시 |
| 효과 | 공격할 때마다 대상에게 **임의의 약한 디버프 1개 추가** (중첩 폭탄) |
| 추가 디버프 풀 | AttackDown, DefenseDown, Poison(1/턴), Burn(1/턴) 중 랜덤 |
| 발동 제한 | 없음 (매 공격) |

**파훼법**: 인퀴지터를 CC로 무력화하거나 한 턴에 처결. 장기전에서는 디버프가 누적되어 Judgment의 추가 데미지가 폭등함. 치유사 Purify로 주기적으로 정리.

**배정 적**: 인퀴지터 (Enemy_Inquisitor)

**구현 훅**: `OnDamageDealtTo(target)` → 랜덤 디버프 1개 적용

### Mirror — 거울

| 항목 | 내용 |
|------|------|
| 색상 | 홀로그램 은색 `rgb(179, 179, 204)` |
| 발동 타이밍 | 마법 데미지 수신 시 |
| 효과 | 받은 마법 데미지의 **25%를 즉시 공격자에게 반사** |
| 특이사항 | 물리 데미지는 반사 안 함 |
| 발동 제한 | 없음 (매 마법 피격) |

**파훼법**: 마법사는 도플갱어에게 약한 스킬만 사용. 도적/전사의 물리 딜이 주력. 또는 마법사의 메테오를 **도플갱어가 Echo로 복사하기 전에** 도적이 Backstab으로 암살.

**배정 적**: 도플갱어 (Enemy_Doppelganger)

**구현 훅**: `OnDamageReceived(attacker, damage, isMagic)` → 마법 여부 체크 후 반사

### Commander — 지휘관

| 항목 | 내용 |
|------|------|
| 색상 | 짙은 금색 `rgb(128, 102, 26)` |
| 발동 타이밍 | 아군 사망 시 |
| 효과 | 아군이 처치될 때마다 자신의 **ATK 영구 +3, DEF 영구 +1** |
| 특이사항 | 소환수 사망도 카운트 (역이용 가능) |
| 발동 제한 | 없음 (매 아군 사망) |

**파훼법**: 소환수를 잡으면 레기온이 강해지는 딜레마 → **레기온 본체를 우선 처결**해야 함. 소환수를 무시하면서 단일 폭딜로 본체 암살. 광역 딜은 소환수 정리에만 제한적으로 사용.

**배정 적**: 레기온 (Enemy_Legion)

**구현 훅**: `OnAllyDied(ally)` → 영구 스탯 증가

### AdaptiveArmor — 적응 장갑

| 항목 | 내용 |
|------|------|
| 색상 | 회청색 `rgb(89, 89, 102)` |
| 발동 타이밍 | 데미지 수신 시 |
| 효과 | **같은 타입(물리/마법) 공격을 연속으로 받으면 저항 +20%** (최대 +60%) |
| 리셋 | 다른 타입 공격 받으면 해당 타입 저항 0으로 초기화 |
| 발동 제한 | 타입별 각각 중첩 |

**파훼법**: **물리/마법 교대 공격** 필수. 전사(물리) → 마법사(마법) → 도적(물리) 순서로 번갈아 때려야 저항이 쌓이지 않음. 단일 타입 극단 파티는 가디안에게 막힘.

**배정 적**: 가디안 (Enemy_Guardian)

**구현 훅**: `ModifyIncomingDamage(damage, type)` → 타입별 저항 중첩 추적

### Regenerative — 재생 핵

| 항목 | 내용 |
|------|------|
| 색상 | 형광 녹색 `rgb(89, 191, 89)` |
| 발동 타이밍 | 턴 시작 |
| 효과 | 매 턴 시작 시 **HP 10% 회복** |
| 조건 | Poison/Burn/Stun 상태가 아닐 때만 발동 |
| 특이사항 | 일반 적 Regenerate(5 고정)와 달리 **% 기반** — 분열 후에도 비율 유지 |

**파훼법**: 도트(Poison/Burn)로 재생 봉쇄가 핵심. 분열로 마이토제 개체가 늘어나면 전체 도트 적용이 필수 (광역 디버프). Stun도 회복을 막으므로 CC기가 유효.

**배정 적**: 마이토제 (Enemy_Mytoze)

**구현 훅**: `OnTurnStart()` → % 기반 HP 회복

## 5. 훅(Call Hook) 시스템 요약

| 훅 메서드 | 호출 시점 | 사용 특성 |
|-----------|----------|----------|
| `OnTurnStart(turnNumber)` | 턴 시작 | Regenerate, Sturdy, PhaseShift, Rampage, Shell, **Regenerative** |
| `ModifyIncomingDamage(damage, type)` | 데미지 계산 중 | Sturdy, **AdaptiveArmor** (type: 물리/마법) |
| `OnDamageReceived(attacker, damage)` | 데미지 받은 후 | Counter, Thorns, Rampage, ArcaneFury, Rally, **Mirror** |
| `OnDamageDealtTo(target)` | 데미지를 입혔을 때 | Corrosive, **Punisher** |
| `PreventDeath()` | 사망 직전 | Immortal, **TemporalAnchor** |
| `ShouldBlockEffect()` | 상태이상 적용 전 | Shell |
| `OnDeath()` | 사망 후 | **Trapper** (지뢰 전폭) |
| `OnAllyDied(ally)` | 아군 사망 시 | **Commander** (영구 버프) |

> **API 확장 필요**: 기존 `ModifyIncomingDamage(damage)`는 데미지 타입(물리/마법)을 인자로 받지 않음. AdaptiveArmor 구현 시 시그니처를 `ModifyIncomingDamage(damage, DamageType type)`로 확장해야 함 (기존 특성은 type 무시).
