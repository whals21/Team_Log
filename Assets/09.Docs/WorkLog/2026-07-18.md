## Phase UI-D: 보완 + 파이프 구축

### 씬 전환 파이프 (★ 핵심)
- **TitleScene → PartySelectionScene**: `TitleSceneSetup.OnNewGame()`에서 `FadeToScene("PartySelectionScene")`
- **PartySelectionScene → MapScene**: `PartySelectionController.OnEmbark()`에서 `SelectedParty` 저장 후 `SceneManager.LoadScene("MapScene")`
- **MapScene**: `MapSceneSetup.Start()`에서 `PartySelectionController.SelectedParty` 체크 → `CharacterSelectUI` 스킵 → `OnCharacterSelectConfirmed(selectedParty)` 직접 호출

### 주요 버그 수정 이력
1. **DestroyImmediate 컴파일 에러** → `UnityEngine.Object.DestroyImmediate`로 수정
2. **LayoutGroup ForceExpand=true로 자식 0 붕괴** → false로 표준화, controlWidth/Height=true로 자식 LayoutElement 존중
3. **특수 Unicode 기호 □ 표시** — `SafeText()` 헬퍴로 ASCII 변환 (⚙→CFG, ⚡→>>, ⚜→제거 등)
4. **"Content" 이름 충돌** — `FindChildRecursive`가 잘못된 위치 찾음 → CarouselContent/BadgeContent/PlateContent/TraitContent로 고유화
5. **★ PartySlotItem "Missing Script"** (가장 심각) — PartySlotItem이 PartySlotPanel.cs 안에 정의되어 Unity 직렬화 시 참조 깨짐 → **별도 파일로 분리**로 해결
6. **자식 Image raycastTarget 가로채기** — Initialize에서 `GetComponentsInChildren<Image>(true)`로 강제 false 설정
7. **인스펙터 바인딩 실패** — `AutoBindMissingFields()` + `AutoBindChildFields()` 런타임 자동 보완

### 가비지 컬렉터 (1차)
- `New Scene.unity` + `.meta` 삭제 (Unity 자동 생성 가비지)
- `CreateSection` 메서드 제거 (CreateSectionSlot으로 대체됨)
- `CreateSectionLabel` 메서드 제거 (섹션 라벨 미사용)

## 학습된 핵심 교훈

1. **★ MonoBehaviour는 한 파일에 하나만** — 가장 시간을 잡아먹은 버그. Unity 직렬화 제한.
2. **LayoutGroup 설정이 전부** — controlWidth/Height + childForceExpand + LayoutElement의 조합이 UI 레이아웃을 결정. 잘못되면 0 크기 붕괴.
3. **인스펙터 바인딩은 불안정** — 빌더가 BindField 호출해도 씬 저장/로드 시 깨질 수 있음. 런타임 자동 보완 필수.
4. **디버그 로그는 적극적으로** — 문제 발생 시 단계별 Debug.Log로 원인 빠르게 파악. 완료 후 제거.
5. **씬을 자주 재빌드** — 코드 수정 후 씬 재빌드 없이 Play하면 이전 상태가 유지되어 디버깅 혼란.
