## Phase CC-2F-1: CorpseComponent 인프라

### 신규
- **`Assets/02.Scripts/Characters/Components/CorpseComponent.cs`** (~140줄)
  - `SkillData[] _slots` (4 슬롯) + `_baseSkills` (리셋용)
  - `IsActive`, `EmpowerBonusNext`, `MassEmpowerBonus`, `SoulLinkRemainingTurns`, `SoulLinkMul`, `KillEmpowerBonus`
  - `ResetToBaseSkills()` — 매 전투 시작 시
  - `Deactivate()` — Necromancer 사망 시
  - `ReplaceSlot(idx, skill)` — 적 처치 시 스킬 교체
  - `GetRandomSkill()` — 매 턴 자동 행동용
  - `GetEffectivePower(skill)` — Power + MassEmpower + KillEmpower
  - `ApplyEmpowerNext/MassEmpower/KillEmpower` + `ConsumeEmpowerNext`
  - `TickSoulLink()` — 매 턴 SoulLink 턴 감소

### 수정
- **`SkillData.cs`** (+15줄) — `_isCorpseSkill`, `_sourceEnemyId`, `_corpseAction`, `_corpseActionValue` 필드 + `CorpseActionType` enum (None/EmpowerNext/MassEmpower/SoulLink)
- **`CharacterData.cs`** (+5줄) — `_corpseBaseSkills: List<SkillData>` 필드 (Necromancer 전용)
- **`Character.cs`** (+20줄):
  - `Corpse` 프로퍼티 + `InitializeCorpseFromData(data)`
  - Health.OnDeath에 시체 자동 Deactivate 훅 연결 ("Necromancer 사망 = 시체도 사망")
- **`KeywordEntry.cs`** (+3줄) — KeywordType에 3종 추가: `SoulLinkMul`, `CurseExtraDamage`, `CorpseKillEmpower`
- **`SkillExecutor.cs`** (+25줄):
  - `ExecuteSkillInternal` 끝에 Mortis 스킬 시체 액션 처리
  - `ApplyCorpseAction(caster, skill)` 헬퍼 — EmpowerNext/MassEmpower/SoulLink 분기
- **`TurnManager.cs`** (+90줄):
  - `_pendingKilledEnemies` 필드 — OnKill 구독하여 적 처치 큐에 추가
  - `StartBattle`에서 시체 리셋 + OnKill 구독
  - `CheckBattleEnd`에서 구독 해제 + 큐 비우기
  - `ProcessCorpseAction()` — ConfirmActions 끝에서 호출. 시체들이 매 턴 자동 시전
    - EmpowerNext/MassEmpower 보정을 powerMultiplier로 변환
    - Soul Link 활성화 시 시체가 준 데미지의 Mul%를 Necromancer 회복
  - `ProcessPendingCorpseSkillSwaps()` — 적 처치 큐 소비, 시체 슬롯 자동 교체
  - `OnEnemyKilledForCorpse(killed)` — OnKill 콜백

### 핵심 설계 결정
- **시체는 별도 Character가 아님** — Necromancer에 종속된 데이터 (caster=Necromancer로 시체 스킬 시전)
- **시체 자동 행동 타이밍** — ConfirmActions(플레이어 턴 종료) 끝, StartEnemyTurn 전
- **시체 스킬 교체는 자동** — 모달 UI 동기화가 복잡하여 자동 교체로 단순화 (무작위 슬롯 ← 무작위 적 스킬)
- **시체 행동 중 보정** — EmpowerNext(1회 소모) + MassEmpower(영구) + KillEmpower(영구)를 powerMultiplier로 변환

## Phase CC-2F-3: 적 처치 시 스킬 교체 (자동화 버전)

### TurnManager.ProcessPendingCorpseSkillSwaps (자동 교체)
- `_pendingKilledEnemies` 큐의 적들에 대해:
  - 죽은 적의 `SkillInventory.Skills`에서 무작위 1개 선택
  - Necromancer 파티의 시체 슬롯 무작위 1개 교체
- 모달 UI 없이 자동 처리 (모달 동기화 문제로 자동화)
- ProcessCorpseAction 시작 전에 큐 소비

### 핵심 설계 결정 (변경)
- 기획서는 Discover Modal로 플레이어가 스킬을 선택하도록 되어 있었으나, **Pipeline 실행 중 모달 동기화가 구조적으로 복잡**하여 자동 교체로 단순화
- 추후 모달 UI 인프라 개선 시 (Pipeline 일시정지 + 모달 대기) 확장 가능
