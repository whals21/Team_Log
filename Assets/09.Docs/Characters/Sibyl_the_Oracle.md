# Sibyl, the Oracle — "보되 바꿀 수 없는 자"

> **캐릭터 상세 설계 문서**. 전체 개편 개요는 [CharacterConceptReview.md](../CharacterConceptReview.md) 참조.
> **11번째 캐릭터 (신규 추가)** — 기존 10캐릭터 슬롯을 계승하지 않고 완전 신규. "시간"이라는 새로운 자원 축 도입.

---

## 1. 정체성 (한 문장)

Sibyl은 **미래를 보되, 그것을 바꿀 수는 없는 예언자**다. 그녀의 모든 스킬은 "1턴 뒤 발동"이라는 지연 페널티를 지불하고, 그 대가로 강력한 효과를 예약한다. 그녀는 싸우는 자가 아니라 **"미래를 청구하는 자"**다.

---

## 2. 배경 스토리

Sibyl은 어린 시절부터 환영을 보았다 — 고향이 불타는 환영, 어머니가 쓰러지는 환영, 자신의 죽음의 환영. 열두 살이 되던 해, 그녀는 처음으로 환영을 말로 꺼냈다. 아무도 믿지 않았다. 서른여덟 명이 죽었다.

그 후로 환영은 더 선명해졌고, 더 자주 왔다. 그녀는 눈을 가리기 시작했다 — 보지 않으면 오지 않을 거라 믿었기 때문이다. 하지만 환영은 눈이 아닌 **마음**으로 왔다. 이제 그녀는 환영을 막지 않는다. 대신 **그것을 끌어안고, 그것이 이루어지기 전에 말한다**. 누군가는 들을 것이다. 아니면 말이다. 어쨌든 환영은 이루어진다.

**이름 어원**: Sibyl = 그리스어 *sibulla* (예언자). 고대 델포이의 피티아, 트로이의 카산드라, 로마의 시빌리나 예언서 — "진실을 말하지만 아무도 믿지 않는 여자"라는 전통 위에 서 있다.

**감정 키워드**: 고독, 체념, 인내, "보이지만 바꿀 수 없는" 고통. "미래는 이미 정해졌다 — 하지만 대비할 수는 있다" — 숙명론적 서사이자, 희망의 실천.

## 4. 역할군 명시

- **주 역할군**: 서포터 (Supporter) — 지연 힐, AP 지원, 정보 활용
- **부 역할군**: 디버퍼 (Debuffer) / finisher — 처형, 디버프 예언

**다른 서포터와의 차별화**:
- **Healer**: "현재 힐" — 즉흥 대응. Sibyl은 "미래 힐" — 사전 예방
- **Bard**: "리듬 버프" — 자원 누적. Sibyl은 "시간 투자" — 자원 이동
- Sibyl은 **타이밍 축**에서만 작동 — Healer/Bard와 같은 파티에서도 역할 충돌 없음

## 5. 핵심 메카닉: Prophecy (예언 — 지연 발동)

### 정의

> **"예언 N" = 스킬 시전 후 N턴 뒤에 자동 발동.** Sibyl의 모든 스킬은 "예언 1" (1턴 뒤, 즉 다음 턴 시작 시 발동).

### 발동 타이밍

```
턴 X: Sibyl 스킬 시전 → "예언" 상태 부여 (카운트 1)
턴 X+1 시작: 카운트 0으로 감소 → 효과 발동
```

→ "1턴 뒤" = **다음 턴 시작 시점에 발동**. 플레이어 턴 시작에 즉시 효과 적용 → 그 턴 행동에 활용 가능.

### 예언의 기본 규칙

| 규칙 | 설명 |
|------|------|
| **중첩** | 한 타겟에 여러 예언 부여 가능 (각각 독립 카운트다운) |
| **발동 시점** | 매 턴 **시작**에 모든 보류 예언 카운트 -1, 0 도달 시 자동 발동 |
| **타겟 사망 시** | 예언 소멸 (위험 부담). 다만 특성 Cassandra's Echo로 보완 가능 |
| **캐스터 사망 시** | 예언 소멸 (캐스터가 죽으면 미래 청구 무효) |
| **시간 붕괴 특성** | 3턴 주기 턴에 Sibyl이 시전하는 스킬은 카운트 없이 즉시 발동 |

### 위력 보상 원칙

동급 일반 스킬 대비 **약 +50~100%** 위력 (1턴 지연 페널티 보상):

| 발명 | 일반 스킬 기준 | 예언 1 (1턴 뒤) 보정 |
|------|--------------|---------------------|
| 단일 공격 | 5~8 | +50~80% (8~14) |
| 광역 공격 | 4~6 | +50~80% (6~10) |
| 힐 | 8~12 | +50% (12~18) |
| 처형 | 임계값 5~10 | 임계값 10 (강력) |

→ **정확한 수치는 밸런스 튜닝 시 결정 (TBD)**. 본 문서는 메커니즘에 집중.

### 핵심 긴장감

> **"이번 턴 1AP를 미래에 투자할까, 지금 당장 쓸까?"**

Sibyl의 모든 스킬이 "1AP + 1턴 뒤"이므로, 매 턴 **미래 가치 vs 현재 가치** 트레이드오프. 위기 상황에서는 즉시 효과가 없어 취약 — 이게 Sibyl의 균형추.

## 6. 스킬 4종 — 모두 "1AP + 1턴 뒤" 패턴

> 4.5 원칙 준수. 4개 스킬이 동일한 비용/발동 패턴을 공유 → Sibyl의 정체성 ("모든 스킬이 미래에 투자"). 조건 다양성은 **강화 조건**(규칙 5A)과 **특성**(3턴 주기 콤보)으로 보완.

| # | 스킬 | AP | 타겟 | 발동 | 기본 효과 |
|---|------|----|-----|------|---------|
| 1 | **죽음의 예언** (Death Prophecy) | 1 | 단일 적 | 1턴 뒤 | HP 임계 이하 시 처형 |
| 2 | **갱생의 환영** (Vision of Renewal) | 1 | 단일 아군 | 1턴 뒤 | 회복 |
| 3 | **미래 차용** (Borrowed Future) | 1 | 자신 | 1턴 뒤 | AP +2 획득 |
| 4 | **데자부** (Déjà Vu) | 1 | 자신 | 1턴 뒤 | 이전 턴 사용 예언 스킬 1개 비용 0 재시전 |

## 7. 스킬 상세

### 1번 — 죽음의 예언 (Death Prophecy)

**메커니즘**: 단일 적에게 "1턴 뒤 처형" 예언 부여. 발동 시점에 대상 HP가 임계값 이하면 즉사, 아니면 효과 없음 (또는 약한 데미지 — TBD).

**강화 조건 후보** (밸런스 튜닝 시 선택):
- (A) 대상 도트 디버프(Burn/Poison/Bleed) 상태 시 임계값 +N (Rogue/Ashe 시너지)
- (B) 캐스터가 다른 예언 보류 중 시 임계값 +N
- (C) 강화 조건 없음 (단순하지만 단조)

**전략**:
- 적 intent로 "이 적이 다음 턴 큰 데미지" 확인 → 죽음의 예언으로 미리 제거
- 도트 디버프 도입 캐릭터(Rogue/Ashe/Alchemist)와 병행 시 처형 임계값 보정으로 보스전에서도 유효
- 일반전에서는 잡몹 HP 30~50 → 임계값 10이면 도트 디버프 1~2개면 처형 가능

**위험**: 보스전에서는 임계값 10이 무의미 (보스 HP 200+). 강화 조건(A) 또는 높은 임계값 필요.

---

### 2번 — 갱생의 환영 (Vision of Renewal)

**메커니즘**: 단일 아군에게 "1턴 뒤 회복" 예언 부여. 발동 시점에 힐.

**강화 조건 후보**:
- (A) 대상 HP 50% 이하 시 힐량 2배 + 정화 동시 (Healer Mercy 특성과 유사)
- (B) 대상이 이번 턴 피격 시 힐량 보너스
- (C) 강화 조건 없음

**전략**:
- 적 intent로 "Healer가 다음 턴 공격당함" → 갱생의 환영을 Healer에게 예약 → 피해 직후 자동 회복
- "미래 힐"이라 위험 — 예약한 아군이 예언 발동 전에 사망하면 예언 소멸
- 반대로, 예약한 뒤 다른 아군이 죽으면 낭비 → **타겟 판단이 핵심 스킬**

**위험**: 즉흥 힐이 아니라 위기 대응 불가. Healer와의 차별화 포인트이자 약점.

---

### 3번 — 미래 차용 (Borrowed Future)

**메커니즘**: 자신에게 "1턴 뒤 AP +2 획득" 예언 부여. 발동 시점에 파티 AP +2.

**핵심**: **1AP 투자 → 1턴 뒤 2AP 환급 = 순이익 +1AP**. StS Conserve Battery를 발전시킨 자원 시간 이동 메카닉.

**강화 조건 후보** (또는 사용 제약):
- (A) 강화 조건 없음 (단순 순이익) — 밸런스 위험. 매 턴 사용 시 +1AP/턴 영구 증가
- (B) 사용 제약: 다른 예언 보류 중일 때만 +2, 아니면 +1 (자원 루프 조건)
- (C) 사용 제약: 런당 N회 (게임 체인저급 예외)
- (D) 강화 조건: 매 턴 첫 스킬 사용 시 +3 (순서 조건)

**전략**:
- "이번 턴 1AP 투자, 다음 턴 고비용 스킬(다른 캐릭터 AP 3) 지원"
- 다음 턴 AP가 많으면 → 데자부 + 다른 예언 스킬 연쇄 가능
- 3턴 주기 콤보의 핵심 — 시간 붕괴 턴에 미래 차용 시전 → 즉시 AP+2 → 다른 스킬 연쇄

**위험**: 정적 밸런스 붕괴 가능성. 매 턴 사용 시 +1AP/턴 = 사실상 AP 자원 시스템 붕괴. (B)(C)(D) 중 하나로 제약 필요.

---

### 4번 — 데자부 (Déjà Vu)

**메커니즘**: 자신에게 "1턴 뒤 이전 턴 사용 예언 스킬 1개를 비용 0으로 재시전" 예언 부여. 발동 시점에 가장 최근에 사용한 예언 스킬(1/2/3번 중 하나)을 비용 0으로 자동 재시전.

**세부 규칙**:
- 재시전 대상: **직전 턴에 Sibyl이 시전한 예언 스킬 1개** (여러 개 시전 시 마지막 스킬 우선, 또는 플레이어 선택)
- 재시전된 스킬도 "1턴 뒤 발동" (예언 카운트 1) — 단, 시간 붕괴 턴이면 즉시 발동
- 재시전 스킬의 타겟: 원본 시전 시 타겟 유지(같은 적/같은 아군), 또는 새 타겟 지정 (TBD)

**전략 — 3턴 주기 콤보의 핵심**:
```
턴 1: 미래 차용 (AP+2 예약)
턴 2: 데자부 (미래 차용 복사) + 다른 스킬 (AP+2로 자원 확보)
턴 3: ⚡ 시간 붕괴 → 데자부/미래 차용 모두 즉시 발동 → AP 대량 환급 + 다른 스킬 연쇄
```

**영감**: StS Echo Form (매 턴 첫 스킬 2회 발동), StS Nightmare (다음 스킬 N회 발동). but Sibyl은 **자신의 예얠 스킬만 복사** + 1턴 지연이 추가된 차별화.

**위험**: 데자부로 복사할 스킬이 없으면 효과 없음 (턴 1에 스킬 사용 안 한 상태에서 데자부 시전 불가/무효). 셋업-소비 루프의 종착지.

## 8. 특성 3종

### 기본 특성 — 죽음의 표식 (Mark of Doom)

> **매 턴 시작 시 무작위 적 1명에게 "죽음의 표식" 부여.** 그 적이 이번 턴 안에 사망 시 → **무작위 적 1명에게 피해 + 무작위 아군 1명 회복** 발동.

**메커니즘 분석**:
- 트리거: 매 턴 시작 (플레이어 턴 + 적 턴 전체 포함 "이번 턴")
- 대상 지정: **무작위 적 1명** (Sibyl 의지와 무관)
- 조건: 그 적이 **이번 턴 안에** 사망 (플레이어 턴 또는 적 턴 동안)
- 보상: 무작위 적 피해 + 무작위 아군 회복 (수치 TBD)

**전략성**:
- 매 턴 무작위 적 표식 → 파티 전체가 "이번 턴은 저 적을 잡자"고 협동
- ItB식 "정보 기반 타겟팅" — 표식이 적 intent와 함께 파티 딜 집중 유도
- 보상도 무작위 → 일관성 부족 but 가변성/재미 ↑

**영감**: 하스스톤 Ragnaros (무작위 대상 타격), DD Mark 시스템, StS Reaper (처치 보상), Persona 5 Baton Pass (연쇄 보너스)

**독창성**: ★★★★★ — "예언이 이루어지면 운명이 연쇄된다"는 테마 메카닭. Sibyl 정체성 완벽 부합.

---

### 메타 해금 1 — 운명의 손 (Hand of Fate)

> **3턴마다 Sibyl의 스킬 1개가 무작위로 비용 없이 자동 시전.** 대상도 무작위 (1번=무작위 적, 2번=무작위 아군, 3~4번=대상 없음).

**메커니즘 분석**:
- 발동 턴: 3/6/9/12... 턴 (시간 붕괴와 **같은 턴** 동시 발동)
- 시전 스킬: 4개 스킬 중 **무작위 1개** (균등 확률 또는 가중치 — TBD)
- 비용: **0** (자원 무상)
- 대상: 스킬 타입에 따라 무작위 (1번=무작위 생존 적, 2번=무작위 생존 아군, 3/4번=자신/글로벌)
- **시전된 스킬도 "1턴 뒤 발동" 예언** (시간 붕괴 턴이면 즉시 발동)

**전략성**:
- "신이 개입한다" — Sibyl 의지와 무관, 운명이 스스로 흘러나옴
- 3턴마다 무상 스킬 = 평균 +0.33 스킬/턴 → 강력 but 무작위 페널티로 밸런스
- 시간 붕괴 턴에 발동 시 즉시 효과 → **3턴 콤보의 폭발력 증폭**

**영감**: Hearthstone Yogg-Saron, D&D Wild Magic Sorcerer, Persona 5 Showtime, StS Velvet Choker(자원 메카닉)

**독창성**: ★★★★ — Hand of Fate와 시간 붕괴가 **같은 턴 발동**이 핵심. 단독이면 운 영향 크지만 시간 붕괴와 결합 시 "매 3턴마다 폭발 턴"이라는 명확한 리듬 형성.

**위험**: 무작위 대상이라 핵심 적(보스)에게 안 가면 낭비. 매 턴 카운트다운 긴장감은 재미 but competitive 측면에선 운 영향 큼.

### 메타 해금 2 — 시간 붕괴 (Time Collapse)

> **3턴마다 이번 턴에 Sibyl이 AP를 사용해서 시전하는 스킬이 카운트 없이 즉시 실행됨.** (3/6/9... 턴에 발동, Hand of Fate와 같은 턴)

**정확한 메커니즘** (사용자 명시):
- 발동 턴: 3/6/9/12... 턴 (Hand of Fate와 같은 턴)
- 효과 대상: **이번 턴에 Sibyl이 직접 AP를 소모하여 시전하는 스킬**
- 효과: 그 스킬들의 "1턴 뒤 발동" 예언이 **즉시 발동** (카운트 0으로 건너뜀)
- Hand of Fate로 자동 시전된 스킬도 포함? (TBD — 포함 시 폭발력 극대, 미포함 시 밸런스 안정)

**전략성 — 3턴 주기 콤보 설계의 핵심**:
```
턴 1-2: 예언 스킬 여러 개 시전 (1턴 뒤 발동 예정)
턴 3: ⚡ 시간 붕괴 턴 → 남은 AP로 스킬 시전 → 즉시 발동
      + ⚡ Hand of Fate → 무작위 스킬 자동 시전 → 즉시 발동
      = 1턴에 여러 예언 효과 동시 폭발
턴 4: 새로운 사이클 시작
```

→ Sibyl 숙련도의 핵심 — **"3턴 째가 오기 전에 예언을 많이 걸어두자"**. 누적 플레이 보상. Hand of Fate와의 완벽 시너지 (같은 턴 발동 = 사용자 명시).

**영감**: StS Burst (다음 스킬 N회 발동), Hearthstone Time Warp (추가 턴), Persona 5 Showtime (조건부 대폭발)

**독창성**: ★★★★★ — "시간이 한꺼번에 도래한다" — 가장 강력한 Sibyl 특성. 매 3턴마다 폭발 턴이라는 명확한 리듬.

**위험**: 시간 붕괴 턴에 시전하는 스킬이 없으면 낭비. Sibyl이 CC(기절 등) 상태이면 무효. AP가 0이면 시전 자체가 안 되니 시간 붕괴도 효과 없음 → **AP 관리가 핵심 과제**.

## 9. 조건 다양성 검증 (규칙 2)

| 스킬 | 기본 조건 | 강화 조건 (후보) | 유형 |
|------|---------|----------------|------|
| 1번 죽음의 예언 | 셋업 (조건 없음) | 도트 디버프 시 임계값 +N | 대상 상태 |
| 2번 갱생의 환영 | 셋업 (조건 없음) | 대상 HP 50% 이하 시 힐 2배 | 대상 HP 임계 |
| 3번 미래 차용 | 셋업 (조건 없음) | 다른 예언 보류 중 시 +2 (사용 제약) | 자원 (자신 예언) |
| 4번 데자부 | 사용 제약: 직전 턴 스킬 존재 | — | 행동 이력 |

**평가**:
- 스킬 자체는 **모두 "셋업(조건 없음)"**에 가까움 → 규칙 2 경계
- but **강화 조건을 각각 다르게 부여** (대상 상태/HP/자원/이력) → 규칙 2 준수
- 추가로 **특성 3종이 모두 다른 조건**(무작위 적 사망/3턴 주기/3턴 주기+AP 사용)으로 매 턴 퍼즐 다양화

→ **스킬 + 특성 합산 시 조건 다양성 충족**. Sibyl은 "스킬 자체보다 특성+3턴 주기 리듬이 퍼즐의 핵심" — 다른 캐릭터와 차별화되는 Sibyl만의 구조.

## 10. 핵심 플레이 루프 — 3턴 주기 콤보

Sibyl의 핵심 재미는 **"3턴마다 폭발 턴"**이라는 리듬. 평소 턴(1, 2, 4, 5, 7, 8...)은 예약만 하고, 3의 배수 턴에 모든 것이 결실.

### 이상적 사이클

```
턴 1: 죽음의 예언 (적 A에게 1턴 뒤 처형 예약)
      + 미래 차용 (1AP → 다음 턴 +2AP 예약)
턴 2: 데자부 (미래 차용 복사) + 갱생의 환영 (아군 힐 예약)
      → 총 4개의 예언 보류
턴 3: ⚡⚡ 시간 붕괴 + Hand of Fate 동시 발동 ⚡⚡
      - 시간 붕괴: 이번 턴 시전 스킬 즉시 발동
      - Hand of Fate: 무작위 스킬 자동 시전 (시간 붕괴로 즉시 발동)
      - 추가로 보류 중이던 4개 예언이 다음 턴 일제 발동 예정
      → 폭발 턴
턴 4: 보류 예언 4개 일제 발동 + 새 사이클 시작
```

### 시나리오 A: 보스전 (딜 집중)

```
적 intent: "보스가 30 데미지로 Duran 공격"
턴 1: 죽음의 예언을 보스에게 (도트 디버프 있으면 임계값 +N)
      + 미래 차용 (다음 턴 AP+2)
턴 2: 데자부 (죽음의 예언 복사 → 보스에게 처형 2회 예약)
      + 갱생의 환영 (Duran에게 힐 예약 — 공격 직후 회복)
턴 3: ⚡ 시간 붕괴 → 죽음의 예언 2개 + 갱생의 환영 1개 즉시 발동
      + Hand of Fate → 무작위 스킬 추가 즉시 발동
      → 보스에게 처형 2회 + Duran 회복 + 추가 효과
```

### 시나리오 B: 다수전 (광역 힐/딜)

```
적 intent: "적 3마리가 각각 다른 아군 공격"
턴 1: 갱생의 환영 (가장 위험한 아군에게 힐 예약)
      + 미래 차용
턴 2: 데자부 (갱생의 환영 복사 → 다른 아군에게 힐 예약)
      + 죽음의 예언 (약한 적에게 처형 예약)
턴 3: ⚡ 시간 붕괴 → 아군 2명 동시 힐 + 약한 적 처형 + Hand of Fate
      → 위기 완전 회복 + 적 1마리 처형
```

### 시나리오 C: 위기 대응 (실패 케이스)

```
적 intent: "보스가 Sibyl 집중 공격"
턴 1: 갱생의 환영을 Sibyl 자신에게 (1턴 뒤 힐)
      → but Sibyl이 턴 1에 사망 → 예언 소멸
      → 위기 대응 실패 — Sibyl은 즉흥 힐 불가
```

→ **Sibyl의 핵심 약점**: 1턴 지연 때문에 급박한 위기 대응 불가. Healer 병행 필수.

## 13. 어센션 시나리오

### 어센션 5 (적 HP +10%, 적 ATK +5%)

- Sibyl의 1턴 지연이 더 위험 — 적 ATK 증가로 예약한 아군이 발동 전에 사망할 위험 ↑
- 죽음의 표식(기본 특성) 보상 가치 ↑ — 사망 빈도 증가로 발동 기회 많아짐
- Hand of Fate 무작위 시전이 더 위험 — 잘못된 타겟에 낭비 시 손해 큼

### 어센션 10 (적 ATK +10%, 파티 MaxHP -10%, 힐 -20%)

- 힐 -20% → 갱생의 환영 효율 ↓. Sibyl의 서포터 역할 약화
- but 미래 차용(AP+2)은 힐 감소 영향 안 받음 → 자원 메카닉 가치 상대적 ↑
- 3턴 주기 콤보가 더 중요 — 매 턴 효율이 떨어지니 폭발 턴 의존도 ↑

### 어센션 15 (적 ATK +10%, 보스 HP +20%, 파티 MaxHP -10%)

- 보스 HP +20% → 죽음의 예언 처형 임계값(10)이 보스전에서 완전 무의미 → 강화 조건(도트 디버프 임계값 +N) 필수
- Sibyl MaxHP 낮음 + 부활 시스템(MaxHP -10% 누적) → Sibyl 자주 사망 → 캐스터 사망으로 예언 소멸 위험
- but 시간 붕괴 + Hand of Fate의 **폭발 턴**이 보스전 역전의 열쇠 — "3턴마다 대폭발"이 어센션 15 보스전에서도 유효

## 14. UI/연출

### 예언 카운트다운 표시

- **위치**: 적/아군 캐릭터 패널에 상태이상 배지와 별도로 "예언" 영역
- **시각**: 진한 청록색(or 금색) 시계 아이콘 + 카운트다운 숫자
- **여러 예언 중첩 시**: 스택형 배지 (예: "⚡×3" — 예언 3개 보류)
- **연출**: 카운트다운 숫자가 줄어들 때 짧은 펄스 (0.2초)

### 죽음의 표식 (기본 특성) UI

- **위치**: 매 턴 시작 시 무작위 적 1명 머리 위에 검은 낫+모래시계 아이콘
- **시각**: 진한 검정/보라색. 표식이 사망 조건 달성 시 폭발 이펙트
- **연출**: 표식 적이 공격당할 때마다 짧은 깜빡임 (위험 강조)
- **플레이어 알림**: "⚡ 이번 턴 표식 적: 고블린 2" — 상단 토스트 or 전투 로그

### Hand of Fate (메타 해금 1) 발동

- **3턴 카운트다운**: Sibyl 캐릭터 패널에 "운명의 손까지 1턴" 표시
- **발동 연출**: Sibyl 머리 위에서 황금빛 손 형상이 내려와 스킬을 가리킴 → 무작위 스킬 자동 시전
- **무작위 시전 시**: 노란색 플로팅 텍스트 "⚡ 운명의 손: 죽음의 예언 시전!"

### 시간 붕괴 (메타 해금 2) 발동

- **3턴 카운트다운**: Hand of Fate 카운트다운과 같은 턴 표시
- **발동 연출**: 화면 전체에 시간 왜곡 효과 (화면 잠깐 흑백 + 시계 바늘 역회전 0.5초)
- **즉시 발동 시**: 예언 스킬들이 황금빛 잔상과 함께 한꺼번에 발동 — 다수 이펙트 동시
- **플레이어 알림**: "⚡⚡ 시간 붕괴! 모든 예언 즉시 발동!" — 강렬한 피드백

### 스킬 연출

- **죽음의 예언**: 적 머리 위 검은 낫이 1턴 동안 천천히 내려옴 → 발동 시 베어넘김
- **갱생의 환영**: 아군 위 황금빛 십자가가 1턴 동안 형성 → 발동 시 빛으로 녹아듦
- **미래 차용**: Sibyl이 시간을 가리키며 모래시계를 뒤집음 → 다음 턴 시작 시 AP 게이지 황금빛 폭발
- **데자부**: Sibyl이 환영을 만들어내며 직전 스킬 흔적이 잔상으로 재현 → 복사된 스킬 시전

### Sibyl 캐릭터 디자인

- **외형**: 눈을 가린 은빛 두건. 손에 수정 지팡이 (시간의 모래시계 상징)
- **의상**: 흰색/은색 로브, 그리스 신전 예언자 복장 + 현대적 디자인 믹스
- **대기 모션**: 몸을 살짝 흔들며 환영에 시달리는 듯한 연출 (주기적으로 머리를 흔들고 안정)
- **시전 모션**: 두건 너머로 빛이 새어 나옴 — "눈을 가렸지만 빛은 보인다"

### 예언 시스템 로직 (의사 코드)

```csharp
// Character 클래스 또는 별도 ProphecyComponent
public class ProphecyComponent {
    private List<ProphecyInstance> _pendingProphecies = new();

    // 스킬 시전 시 예언 부여
    public void AddProphecy(SkillData skill, Character caster, Character target) {
        var instance = new ProphecyInstance {
            Skill = skill, Caster = caster, Target = target,
            Countdown = skill.ProphecyDelay, TurnNumber = GetCurrentTurn()
        };
        _pendingProphecies.Add(instance);
    }

    // 매 턴 시작 시 호출
    public void OnTurnStart() {
        foreach (var p in _pendingProphecies.ToArray()) {
            // 시간 붕괴 특성 활성 턴이면 카운트 건너뜀
            if (HasTimeCollapseTrigger() && p.Caster == Sibyl && IsCastThisTurn(p)) {
                p.Trigger();
                _pendingProphecies.Remove(p);
                continue;
            }
            p.Countdown--;
            if (p.Countdown <= 0) {
                p.Trigger();
                _pendingProphecies.Remove(p);
            }
        }
    }

    // 타겟 사망 시 예언 소멸
    public void OnTargetDeath(Character deadTarget) {
        _pendingProphecies.RemoveAll(p => p.Target == deadTarget);
    }
}
```

- `TurnManager.OnTurnStart` → ProphecyComponent.OnTurnStart + Hand of Fate 체크 + 시간 붕괴 체크 + 죽음의 표식 부여
- `Character.OnDeath` → ProphecyComponent.OnTargetDeath + 죽음의 표식 발동 체크
- `CombatEventBus.OnSkillUsed` → 데자부 복사 대상 추적

## 18. 핵심 디자인 철학 요약

Sibyl은 **"미래를 자원으로 쓰는 최초의 캐릭터"**다.

1. **모든 스킬이 미래에 투자** (1AP + 1턴 뒤) — 명확한 정체성
2. **3턴마다 폭발 턴** — Hand of Fate + 시간 붕괴 동시 발동 → 독창적 리듬
3. **정보 기반 전략** — 적 intent를 보고 예약하는 ItB식 퍼즐
4. **무작위와 운명** — 죽음의 표식/Hand of Fate로 "운명을 받아들이는" 테마
5. **파티 시너지 정점** — Ashe(Lumi)/Duran과 결합 시 최대 효율

"보되 바꿀 수 없다"는 철학은 플레이로 체험된다 — 플레이어는 미래를 **바꾸는 게 아니라 대비하는** 존재가 된다. 이것이 Sibyl만의 독창적 재미.
