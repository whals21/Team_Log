### ★ 47-50: 전투 경험 개선 파생 인사이트
- **(47) 시뮬레이터 ProcessBattleEnd 호출 누락**: GameRunState의 핵심 로직(부활/풀힐)이 시뮬레이터에서 누락되면 사망 패턴이 완전히 왜곡됨. OnBattleVictory는 BattlesWon++만 수행. 실제 힐/부활은 ProcessBattleEnd(victory)에 있음. 클리어율 17% → 68% 차이가 이 하나로 발생.
- **(48) 에이전트 정성 분석은 코드 읽기 검증 필수**: 4에이전트 심층 분석 중 5개 항목(P0-2 스폰, P1-2 도트 데미지, P2-1 투사체 색상, P2-3 드로우 애니 등)이 "미구현"이라고 보고했으나 실제로는 모두 사전 구현 상태. .asset 파일과 연결 로직까지 직접 읽어야 정확.
- **(49) StS 표준 "연속 사용 패널티"는 인스턴스 단위**: EnemyActionPattern의 `_lastUsedIndex`는 매 전투 새 인스턴스이므로 전투 간 상태 유지 없음. 시뮬레이터/런타임 양쪽에서 안전.
- **(50) 옵션 C 하이브리드 튜토리얼**: 전체 화면 오버레이는 Phase DIR 연출을 가림. 하단 작은 카드만 배치 + 카드 영역만 raycastTarget=true가 정답. 게임 플레이/연출 방해 최소화.

- BattleSceneSetup._useTestData가 편의용 기본값이었으나, 정상 런 파이프라인에서 override되지 않아 테스트 데이터가 계속 사용됨
- 이런 "에디터 편의 기본값"은 기본 false + 명시적 true 설정 패턴이 안전
- 증상: 튜토리얼 스킵 + 보스 HP 비정상 등 다양한 왜곡
- 교훈: 정상 런에서 이상 동작 시 SerializeField 디버그 값 먼저 의심
