# 2026-06-03 작업일지

## 적 특성(Enemy Trait) 시스템 전면 개편 + 일반 적 확충

### 개요
기존 8종 적 특성 중 전략적 가치가 낮은 4종을 교체하고, 파훼 가능한 전략적 특성 4종을 신규 설계. 일반 적 4종(해골 전사, 늑대, 독버섯, 박쥐)을 추가하여 전투 다양성 확보. 전체 데이터 카탈로그 문서 3종을 신규 작성.

---

## 1. 특성 시스템 개편 (4종 교체)

### 교체 사유 및 내용

| 적 | 기존 특성 | 문제점 | → 새 특성 | 파훼법 |
|----|----------|--------|----------|--------|
| 슬라임 | ShieldPrep | "HP 5 더 많은 몬스터"와 동치, 전략 없음 | **Regenerate** | 도트(Poison/Burn)로 재생 봉쇄 |
| 고블린 | Agile | 순수 RNG 25% 회피, 파훼 불가, 불쾌감 | **Opportunist** | HP 균등 분배로 타겟 유도 |
| 고블린 왕 | Enrage | ArcaneFury와 메커니즘 동일 (ATK 증가 수치만 다름) | **Rally** | ATK+8 DEF+4 동시 획득, 임계점 관리 |
| 드래곤 | ScaleArmor | "HP 43% 더 많은 몬스터"와 동치, 전략 없음 | **Rampage** | 매 턴 공격 분배로 누적 리셋 |

### 유지된 특성 (4종)
- **Sturdy** (견고): 매 턴 첫 타 50% 감소 — 약한 스킬로 장갑 벗기기
- **ArcaneFury** (마력 폭주): HP 50% 이하 시 ATK +5 — 임계점 버스트
- **Corrosive** (부식): 피격 대상 방어감소 — 맞을 사람 지정
- **Immortal** (불사): 1회 HP 1 생존 — 2킬 플랜

### 신규 특성 설계 기준
- 예측 가능: 플레이어가 발동 조건을 인지하고 대비 가능
- 파훼 가능: 특정 전략(타겟팅, 스킬 선택, 턴 순서 등)으로 대응 가능
- 의사결정 변경: 평소와 다른 플레이를 유도
- 발동이 체감: 특성 발동을 플레이어가 인지 가능

## 2. 신규 일반 적 (4종 추가)

### Enemy_Skeleton — 해골 전사
- **컨셉**: 생과 사를 오가는 언데드 기사
- **특성**: PhaseShift (위상 변이) — 홀수 턴 DEF+4, 짝수 턴 ATK+4
- **스탯**: HP 32, ATK 6, DEF 2
- **스킬**: 베기, 뼈 투척, 방어 태세, 뼈 울림
- **파훼법**: 짝수 턴에 방어, 홀수 턴에 공격

### Enemy_Wolf — 늑대
- **컨셉**: 날카로운 이빨을 가진 사나운 맹수
- **특성**: Counter (반격) — 피격 시 공격자에게 고정 3 데미지 반격
- **스탯**: HP 28, ATK 8, DEF 1
- **스킬**: 물기, 울부짖기, 돌진, 냄새 맡기
- **파훼법**: 단일 강타로 공격 횟수 최소화, 도트로 우회

### Enemy_Mushroom — 독버섯
- **컨셉**: 건들면 독이 튀는 거대한 버섯
- **특성**: Thorns (가시) — 받은 피해의 30% 반사
- **스탯**: HP 25, ATK 4, DEF 2
- **스킬**: 포자 확산, 박치기, 재생, 맹독 안개
- **파훼법**: 약한 공격으로 반사 최소화, 도트로 우회

### Enemy_Bat — 박쥐
- **컨셉**: 초음파로 사냥하는 박쥐 떼의 우두머리
- **특성**: Shell (껍질) — 매 턴 첫 상태이상 무효화
- **스탯**: HP 22, ATK 5, DEF 1
- **스킬**: 초음파, 흡혈, 회피 비행, 저주 소리
- **파훼법**: 쓸모없는 상태이상을 먼저 걸어 Shell 소모

## 3. 코드 변경

### EnemyTrait.cs (전면 재작성)
- `EnemyTrait` enum: 8종 → 12종 (Regenerate, Opportunist, PhaseShift, Counter, Thorns, Shell 추가)
- `EnemyTraitHandler` 클래스:
  - `OnTurnStart(int turnNumber)`: turnNumber 파라미터 추가 (PhaseShift용)
  - `OnDamageReceived(Character attacker, int damage)`: attacker/damage 파라미터 추가 (Counter/Thorns/Rampage용)
  - `ShouldBlockEffect()` 신규 메서드 (Shell용)
  - PhaseShift: 홀짝 턴 교대 스탯 적용 로직
  - Rampage: 피해 미수취 시 ATK 누적, 피해 수취 시 초기화 로직
  - Rally: 임계치 발동 시 AttackUp + DefenseUp 상태이상 적용

### TurnManager.cs
- `DealDamage`: `OnDamageReceived(attacker, calculatedDamage)`로 시그니처 확장
- `StartNewTurn`: `OnTurnStart(_context.TurnNumber)`로 turnNumber 전달
- `ApplyEffect`: Shell `ShouldBlockEffect()` 체크 추가

### EnemyAIController.cs
- `SelectRandomAlivePlayer`: Opportunist 특성 시 최저 HP 타겟 선택, Taunt 무시
- `ApplyEffect`: Shell `ShouldBlockEffect()` 체크 추가

### BattleDisplayUtil.cs
- `GetTraitLabel`, `GetTraitColor`, `GetTraitDescription`: 12종 특성 전체 매핑 업데이트
