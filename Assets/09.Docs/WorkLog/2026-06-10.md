## 1순위: TurnManager 분해 (570줄 → 260줄)

### 문제
TurnManager가 9가지 책임을 가진 God Class였음:
- 턴 라이프사이클 관리
- AP 관리
- 대상 결정 (타겟팅)
- 데미지 계산 + 특성/유물 훅
- 스킬 실행 (공격/힐/버프/디버프/쉴드/정화)
- 증강 해석
- 키워드 해석
- 적 턴 처리
- 전투 종료 판정

### 해결: 3클래스 분리

**DamageCalculator.cs** (105줄, 신규) — `TeamLog.Combat`
- `CalculateDamage(int atk, int def)`: 공식 계산
- `DealDamage(Character attacker, Character target, int baseDamage)`: 특성 훅 + 유물 훅 + 카운터 데미지 + 킬 이벤트
- `OnAttackMissed` static 이벤트
- TurnManager + EnemyAIController 모두에서 호출

**SkillExecutor.cs** (264줄, 신규) — `TeamLog.Combat.Turn`
- `ExecuteSkillInternal()`: 타겟별 스킬 실행 진입점
- `ExecuteAttack/ExecuteHeal/ApplyEffect/ExecuteShield/ExecutePurify`: 스킬 타입별 처리
- 증강 해석 (Spread, Pierce, Chain, Drain 등)
- 키워드 해석 (PowerMul, CostAdd, DamageDealtHealPercent 등)
- `GetKeywordSumForCharacter/GetKeywordMulForCharacter` static 헬퍼
- `OnSkillApplied` static 이벤트
- 생성자에서 `_playerParty`, `_enemies` 수신

**TurnManager.cs** (260줄, 리팩토링)
- 순수 턴 오케스트레이터: 라이프사이클, AP, 대상 결정, 적 턴, 전투 종료
- 내부에서 SkillExecutor 인스턴스 생성
- `ExecuteSkillImmediately`: 대상 결정(switch on TargetType) 후 SkillExecutor에 위임
- `ExecuteFallbackEnemyAction`: DamageCalculator.DealDamage 호출

### 호출자 업데이트
- `EnemyAIController`: `TurnManager.DealDamage` → `DamageCalculator.DealDamage`
- `BattleSceneSetup`: `TurnManager.OnSkillApplied` → `SkillExecutor.OnSkillApplied`
- `BattleSceneSetup.Events`: 이벤트 구독/해제 대상 변경
- `TurnManagerTests`: `TurnManager.CalculateDamage` → `DamageCalculator.CalculateDamage`

- `IsAugmentCompatible`: 중복/슬롯/타입 호환성 체크

**GameRunState.cs** (275줄, 리팩토링)

## 3순위: 중복 헬퍼 추출 (MapSceneBuilder.Panels.cs 673줄 → 601줄)

### 문제
MapSceneBuilder.Panels.cs에 동일한 UI 생성 패턴이 반복:
- 오버레이 패턴 ×8 (CreateFullImage + SetActive(false) [+ CanvasGroup])
- ScrollRect 보일러플레이트 ×3 (~18줄씩)

### 해결

**MapSceneBuilder.Helpers.cs**에 2개 헬퍼 추가:
- `CreateOverlay(name, parent, color, withCanvasGroup)`: 오버레이 패널 + 비활성화 + 선택적 CanvasGroup
- `CreateVerticalScrollView(name, parent, spacing, childAlignment)`: ScrollRect + Viewport + Content(RectMask2D, VerticalLayoutGroup, ContentSizeFitter) → content RectTransform 반환

**MapSceneBuilder.Panels.cs**: 8개 오버레이 + 3개 ScrollView 패턴을 헬퍼 호출로 교체
